# 画面表示

状態：設計中。拡大方法と改善範囲は合意済み。全画面ボタンの入口と、埋め込み実行での扱いを確認する。

## 合意した方針

- 拡大されない症状は、GodotエディターからF5・F6で起動する埋め込み実行で発生している。
- 埋め込み実行では「Keep Aspect Ratio」を使い、実行画面の大きさに合わせて縦横比を保って表示する。
- ウィンドウを大きくしたときは、キャラクター、地形、文字、ボタンを一緒に拡大する。ステージ内で一度に見える範囲は同じにする。
- 改善範囲は、縦横比を保つ自動拡大、全画面切替ボタンとF11、前回のウィンドウサイズと全画面状態の記憶とする。
- 自動ポーズの追加は今回の対象に含めない。

## 埋め込み実行の表示

GodotのGame画面上部にあるサイズ設定で「Keep Aspect Ratio」を選ぶ。Gameバーのある別ウィンドウも埋め込み実行に含まれる。既定の「Fixed Size」では、表示はプロジェクトで指定したサイズに固定される。

この選択はプロジェクトごとのエディター設定に保存され、`project.godot`には保存されない。Godotの操作は[公式ドキュメント](https://docs.godotengine.org/en/4.7/tutorials/editor/game_embedding.html#embedded-window-sizing)を参照する。

埋め込み実行中は、ゲーム側から全画面などのウィンドウモードへ切り替えられない。[公式ドキュメントの制約](https://docs.godotengine.org/en/4.7/tutorials/editor/game_embedding.html#limitations)に従い、ゲーム内の全画面切替と表示設定の記憶は単独実行向けにする案を確認する。

## 現在の実装と確認結果

`project.godot`は基準サイズ1280×720、`canvas_items`による拡大を設定済み。Xvfb上のGodot 4.7.2で独立ウィンドウを変更し、1280×720では1倍、1920×1080では1.5倍、1600×1200では1.25倍で上下に各150pxの余白が付くことを確認した。いずれもステージ内で見える範囲は1280×720のままだった。

ユーザー環境での埋め込み実行は再現していない。全画面切替と表示設定の保存は未実装。
