# 回廊の第25〜30室と左右の運搬

[Issue #159](https://github.com/Foxy-null/2d-space/issues/159)。合意済みの[探索設計](celeste-exploration-design.md)に沿い、既存24室の原点・主地形・7つの巻物IDと共有Player/ギミック物理を保って6室を追加する。第24室の緑と赤の実選択は第25室への中継とし、第30室だけにGoalを置く。実配置の巻物は9個。

実装前には「回復→靴、右からSpring→反転、保持壁キック→風、反射→反転、右から靴→反射、回復→Spring」という6案と、8方向Dash・移動した相棒の背・上投げ/手ぶら登り・休憩からの省略を比較する方針を先に記録した。初見の総所要時間を増やすための待ち時間や履歴ロックは加えない。

| 室 | 原点X / 幅 / 高さ | 完成した主経路 |
|---|---|---|
| 25 | 37120 / 1920 / 2200 | 相棒と空中のDash回復から660px上の棚へ。靴を使って560px左上へ折り返し、右の高台から出口へ |
| 26 | 39168 / 1920 / 2200 | 右入口のSpringから650px上の棚へ。Upで天井へ運び、右側のDownで床へ戻り、左出口へ |
| 27 | 41216 / 1920 / 2200 | 相棒保持の壁キックで1300px上へ。高い横風と斜め上Dashで650pxの隙間を渡り、さらに250px上の棚から出口へ |
| 28 | 43264 / 1920 / 2000 | 円の反射で580px上の棚へ。Upから天井へ進み、Downで床側へ戻って右の出口へ |
| 29 | 45312 / 1920 / 2200 | 右から靴と相棒で560px上へ。棚の左へ降りて円の反射から580px上の棚へ。右上へ折り返してから左出口へ |
| 30 | 47360 / 1920 / 2200 | 空中回復から660px上の棚へ。Springと相棒で650px上がり、左右へ折り返して実到着台へ運ぶ |

第26・29室は右入口・左出口。床、Spawn、相棒、境界トゲ、出口の片面床、枠入り運搬アイコン、矢印とチェック印を実際の向きにそろえる。旧24室の右進行は変えない。新室の原点は128pxずつ間隔を取り、左出口の外壁が前室の出口へ張り出して進行を止めないようにする。第24室の緑と赤はどちらも通常の転送で元の位置へ戻り、第25室では自室の緑を再取得する。赤の例外条件は第24室だけに保つ。

操作間の実棚では検査用に3秒静止する。3秒は増量や通常の攻略時間の評価に算入せず、下表には再挑戦の上限を確認するため含める。長距離を歩いたり待つことで時間を稼がない。

## 任意の巻物と見通し

- 第25室の `companion/refill_upper_08` は、回復と靴の後の上棚から左上の(140,650)へ寄る。幅190・上面720の棚へ着地して確定し、同じ上面880の主経路へ戻る。
- 第28室の `companion/inverted_left_09` は、反射・Up・Downを終えた床から左上の(460,500)へ寄る。幅200・上面580の棚で確定し、同じ上面750の主経路へ戻る。

既存の小さい巻物印だけを入口へ置き、新しい常設説明は加えない。通常主経路は両方とも未取得のまま進める。主人公と実保持物を隠さないHUD位置と、休憩から実際の次の仕掛けまたは広い安全面が見えるカメラを検査する。第27室では壁頂から風の全体と島の220pxの安全面が見えるよう右へ視野を寄せる。第28室の入口下層はカメラの下端だけ80px広げ、下に降りる最初の反射球全体を見せる。部屋や死亡境界は変えない。第29室の中層は下の反射も見える高さ、第30室のHUDはSpringと実体を避けた左上へ置く。左進行の下段と第28室のDown後は次の足場側へ小さく視野を寄せる。第28室の巻物棚付近だけHUDを右上へ移し、帰還先に幅220pxの見える安全面を保つ。旧24室の地形と課題は保ち、第24室から新しい出口端まで赤い傘を運ぶ際は、全体が画面へ収まるよう出口の高さだけカメラ右端を20px広げる。

初案では第27室の風がなくてもJump・12f後の上Dash・相棒Jumpで島へ着地できた。島を高く遠くへ置き、風の室内設定と正規の斜め上Dashを合わせた。共有Wind/Playerは変更していない。風は静止棚から外し、通常と弱入力の正規6条件と、風なし56例を比較した。

`corridor_fifth_route_test.gd` は全36経路・329,889項目で成功。実静止3秒、主経路で未取得、実次室と最終Goal、9個のnative巻物の一意性を含む。HintONの通常操作中（転送演出中を除く）の各物理frameで36×52の実体と実保持物のviewport内、Info・Hint・Pause・表示中のクリア通知との非重複を確認する。終了時にObjectDBが2件残る警告があり、実行中のスクリプトエラーはなかった。

`corridor_fifth_required_test.gd` の計416例（`--steps` を含む）は、回復/靴/Spring/反射/Up/風/壁キック/追加Jumpを個別に省く8方向Dashと、実際に移動して支えにした相棒48例を含む。風の比較は12/20/28/36/44/52/60f。`--extras` の64例は、実反転天井からDownを使わず出口へ向かう40例と、第29室の実休憩へ運んだ相棒の背から同時Grab/Jumpを行い、反射を省く24例。計480の有限入力例で対象への省略到達はなかった。既存の上投げ試験 `corridor_throw_climb_test.gd -- --fifth-shaft` でも12例37項目が成功し、全12例で実際の手ぶら上登りを行った上で、相棒を再取得して壁キックの代わりに進めなかった。初期化に失敗した入力を負例には数えない。

`corridor_fifth_retry_test.gd` は54,637項目で、新6室のR・実トゲ信号による接触死・自室Spawn/相棒/資源の復元・その後の全攻略、左室の両場外境界、旧24室の緑/赤それぞれの実接続と自室相棒の再取得を確認した。終了0・警告なし。

`corridor_fifth_scroll_test.gd` は通常/弱入力で42,080項目。未確定のR・実落下・途中帰還は取り消され、実静止棚で確定した後はR・実落下・再訪・途中帰還と再読込で保持された。正例の通常操作中（転送演出中を除く）ではHintONの毎frameの実体/保持物/HUDも確認。入口から元の棚への往復は25室7.52/7.30秒、28室7.05/7.08秒（通常/弱、静止3秒込み）。実入口から最後の出口までを足した総時間は別に20.65/21.02秒、17.33/18.53秒だった。別プロセスの `corridor_fifth_reload_test.gd` 5項目で実保存、選択の「2 / 9」と読み上げ名、薄い再訪表示も確認した。保存先はPID付きの専用ファイルで、本物の保存は変更しない。

全30室は `stage_4_test.gd` の1,125項目で成功。実29転送・最終Goal、全室の手ぶら出口拒否、天井トゲ・巡回・復帰・ヒント/ポーズ・メニュー/再入場と最終バッジの配置を含み、終了0・警告なしだった。

旧7枝は `corridor_more_test.gd` 257項目、`corridor_wide_route_test.gd` 8,173項目、`corridor_fourth_scroll_test.gd` 31,610項目で再確認した。旧第24室の赤通常/弱×16/20/24fと緑の正当なSpring代替は `corridor_fourth_choice_test.gd` 31,143項目で第25室へ接続した。すべて終了0・警告なし。第24室の新出口への接続確認では赤の保持物の右端が約1px画面外に出る入力を実測し、出口付近のカメラ右端を20px広げて解消した。

第28室の入口から最初の反射球が下半分画面外になる画像を受け、上記カメラ修正と実bounds観測を加えた。第28室全6条件は45,525項目で再確認し、反射球の範囲は画面Y544〜672に収まった。

巻物棚のUIを調整した最終配置でも、両枝の通常/弱入力の往復と毎frame観測を41,924項目で再確認した。第28室は100pxだけ見えれば通っていた検査を220pxへ強め、HUDが帰還先を覆う実画像に合わせて修正した。

native描画は `corridor_fifth_route_test.gd -- --screenshots` の本編21枚（53,123項目、下端調整後の第28室だけ7,365項目で更新）と、`corridor_fifth_scroll_test.gd -- --screenshots --stage-only --strong` の巻物8枚を `docs/screenshots/corridor-fifth/` へ保存する。入口・3秒静止棚・後半の足場に加え、第26/28室の反転天井、第30室の実Goal、巻物入口の印・仮取得・確定棚・自然帰路を原寸で確認した。最新main `6b3b1e7` へ統合後は `--selection-only --strong --keep-fixture` の20,541項目で通常の両枝を再攻略し、選択画面2枚を更新した。全31枚を目視し、チュートリアル8/塔6/重力8/回廊9/峡谷7を保ち、取得数の1 / 9・2 / 9とaccessible名を確認した。描画ジョブはすべて終了0、V-Sync切替不可というXvfbの環境警告だけだった。

統合後の別プロセス再読込5項目と、PID保存を隔離した `stage_select_test.gd` 144項目・`stage_clear_test.gd` 71項目でも成功した。いずれも終了0・警告なし。初見の総所要時間、任意の入力列の完全な不可能証明、実機ゲームパッドは引き続き未確認。
