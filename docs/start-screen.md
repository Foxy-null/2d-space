# スタート画面

仕様の検討中。画面の実装は合意後に行う。

## 確定している要件

- ゲームの入口にスタート画面を設ける。
- 作品のロゴを画面中央に表示する。
- STARTを押すと既存のステージ選択画面へ進む。

## 既存の状態

- 起動するとステージ選択画面を直接表示する。
- 用語集と既存画面の作品名は「忍者ぶっとびくん Galaxy」。今回の指定は「忍者ぶっとびくんgalaxy」であり、ロゴの表記は確認する。
- 専用のロゴ画像はなく、既存画面の作品名は文字で表示している。
- 基準の画面サイズは1280×720。
- ステージ選択はクリック、キーボード、ゲームパッドに対応している。
- プレイ中とクリア後の戻り先はステージ選択画面。

## 設計の分岐

```mermaid
flowchart TD
    A[確定：中央にロゴ、STARTから既存のステージ選択へ] --> Q1[Q1：ロゴの文字表記]
    A --> Q2[Q2：ロゴと背景の見た目]
    A --> Q3[Q3：STARTの入力方法]
    A --> Q4[Q4：ステージ選択からスタート画面へ戻る操作]
    Q1 --> R[回答に応じて残りの判断を確認]
    Q2 --> R
    Q3 --> R
    Q4 --> R
    R --> C[仕様全体の合意後に実装]
```
