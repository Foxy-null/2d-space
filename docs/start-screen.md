# スタート画面

起動時は、既存のユーザー提供ロゴと「はじめから」「つづきから」を表示する。背景は新しい第1面の開始地点と共通の `TutorialLandscape` を使い、城・黒い空・白い星と雲・地形を表示する。背景にはプレイヤーや衝突判定を作らず、表示だけで進捗を更新しない。

## 選択と保存

| 項目 | 動作 |
| --- | --- |
| はじめから | 全5面のクリア印・巻物・操作設定・画面設定をリセットし、第1面へ直接進む |
| つづきから | 記録を保持してステージ選択へ進む。保存がなければ無効 |

既存の進捗または変更済みの操作・画面設定があるときだけ、初期化の確認を表示する。確認は「戻る」を初期選択とし、「初期化してはじめる」で実行する。キャンセルでは何も消さない。初回は確認なしで開始し、その時点で開始済み保存を作る。保存に失敗した場合は開始せず、エラーを表示して元のデータを復元する。

保存がある場合は「つづきから」、ない場合は「はじめから」にフォーカスする。クリック、方向キー＋Enter/Space、ゲームパッドの十字キー/左スティック＋下ボタンで選択する。選択画面から「タイトルに戻る」、Esc、Back/Selectで戻れる。

## 表示

基準サイズは1280×720。既存ロゴの縦横比と忍者の登場・跳び出しを維持し、2つのボタンをロゴの下へ置く。透明なボタンは登場前にクリックを受け取らない。キーボードとパッドの決定は登場中でも選択中の項目を実行できる。OSから動きの抑制を取得できた場合は、背景・ロゴなどのアニメーションを止めて即表示する。

## 実装と確認

- `scenes/start_screen.tscn` / `scripts/start_screen.gd`：レイアウト、選択、初期化確認、遷移。
- `scripts/collection_progress.gd`：開始済み保存と全初期化。詳細は [進行仕様](game-progress.md)。
- `scripts/tutorial_landscape.gd`：コース・タイトル・選択で共有する景色。
- `tests/stage_select_test.gd`：実際のキー・パッドイベント・マウスによる往復、フォーカスと各カードの範囲。
- `tests/game_progress_test.gd`：確認のキャンセルと実行、再開、全設定を含む初期化と保存失敗時の復元。

実行方法と実機未確認の範囲は [検証記録](tutorial-stage-1-implementation.md)を参照する。ロゴの出典は [タイトル素材](../assets/ui/PROMPTS.md)。旧STARTのみの画面は今回の2項目へ置き換えた。
