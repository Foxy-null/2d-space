# 渓谷31〜33室の設計と検証

Issue #170。出発点は main `1a19ca6874c148d9baee3624bd6f7320fd37e75e`。既存30室の地形・9個の巻物IDと共有Player物理を保持する。旧30室のGoalだけを次のチェックポイントへ置き換える。

## 検証する仮説

31室は入口のブーツと追加ジャンプを最初の高い反発へつなぐ。32室は反転した前半の反発から、中間のDown・通常の足場・空中回復を経て後半へ進む。33室は反発の勢いから高い壁を登り、高い後半の反発へ接続する。31・33室には上または左への任意の巻物の寄り道を置き、同じ本線へ戻れるようにする。

すべて形状だけの仮説であり、実入力で確かめるまで通行可能・必須とは扱わない。実axis 1.0/0.8と16/20/24fの操作間隔、有限の省略比較で調整する。チェックポイント間の成功ルートと寄り道往復は30秒未満を目安とし、待機3秒も含めて記録する。不要な補助ラベルや履歴ロックは増やさない。

## 実際に再現して修正した問題

- 実ブーツ取得直後のRで、再出現までの2.5秒が残った。赤試験で再現後、新2資源だけをPlayerの`respawned`から既存`reset_for_respawn`へ直接接続した。共通Playerは変更しない。実Boot/Refill消費後R、実死亡、弱入力での再攻略、旧30から新33までの実接続、縦トゲ3レーンの実hitは47,315項目・終了0で通過した。
- 第31室の巻物への左上入口でInfoが巻物を隠した。第3反射後に左上へ向かう範囲ではInfoを下へ退避し、巻物・印・帰還する床の実矩形を検査した。確定棚では右下へカメラを先読みし、次のRest全体を画面とHUDの外側へ収める。
- 第32室の反転RestではDownの下端50pxと着地床全体が画面外だった。実native赤試験の矩形はDownがY610〜770、床がY840〜856。休憩中だけカメラを下へ220px向け、InfoをY8、HintをY650へ置いた。初稿は入口の重力切替直後にも適用されたため不採用とし、Y900〜1100の実休憩範囲に限定した。6条件の全身/HUD検査と、Down・着地床・Rest・次反射の実矩形検査を通過した。
- `upper_branch`の型推論エラーが出た起動試験は不合格として除外し、明示boolへ修正した。終了0や成功文字列があってもSCRIPT ERRORを含む実行は合格としない。

## 再現

共有環境では`/tmp/celeste-godot-slot.py`経由で1本ずつ起動し、終了後2秒空ける。Godotの主な引数は以下。大型の旧ルートは成功markerが出るまで待ち、短いquit上限だけで成功と判定しない。

```sh
--headless --fixed-fps 60 --path . --script res://tests/canyon_applications_route_test.gd -- --hints
--headless --fixed-fps 60 --path . --script res://tests/canyon_applications_required_test.gd -- --case=refill --offset=0 --count=4
--headless --fixed-fps 60 --path . --script res://tests/canyon_applications_recovery_test.gd
--headless --fixed-fps 60 --path . --script res://tests/canyon_applications_scroll_test.gd -- --weak --hints --keep-fixture
```

別プロセスには出力された`CANYON_APPLICATIONS_SAVED_PATH`を環境変数`CANYON_APPLICATIONS_FIXTURE`へ渡し、`canyon_applications_reload_test.gd`を実行する。nativeはheadlessを外し、`--rendering-method gl_compatibility --audio-driver Dummy --disable-render-loop`と`--screenshots`を使う。

初見の人による評価・実機ゲームパッド・本編9〜15分/巻物込み15〜24分は引き続き未達・未検証。部屋数や検査待ちだけで達成済みにしない。
