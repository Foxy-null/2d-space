# ゲーム進行・はじめから・つづきから

状態：実装済み。2026-10-30。Q26・Q27・Q31〜Q33・Q35・Q37と、操作設定・画面設定も含めるというQ33の補足を反映。テストでは使い捨ての保存先を使い、実際のプレイデータは変更していない。

## タイトルと再開

| 項目 | 挙動 |
| --- | --- |
| はじめから | 全進捗と操作・画面設定を初期化し、第1面へ直接入る |
| つづきから | クリア印・巻物を保持してステージ選択へ入る。保存がなければ無効 |

新規開始時に未クリア・未収集でも開始済み保存を作り、その後は再開できる。全5面は最初から自由に選べる。部屋や途中のチェックポイントは保存せず、面を選び直すと最初から始まる。

タイトルと選択の背景は、第1面の開始地点と共有する。背景表示やメニュー操作だけでプレイ・収集・進捗更新を発生させない。

## 全初期化

全5面のクリア印、巻物、プレイ中の状態、キーボード・マウス・ゲームパッド配置、ウィンドウサイズと全画面設定を全て初期化する。ユーザーは操作・画面設定も含めると明示した。

既存の進捗または変更済み設定がある場合だけ確認を表示する。「初期化してはじめる」で実行し、「戻る」では何も消さない。初回で消すデータがない場合は確認しない。

3つの保存ファイルとメモリを退避してから初期化し、途中の保存に失敗した場合は元へ戻してエラーを表示する。確認を開いただけでは初期化を呼ばない。

## クリアと移行

最終条件を満たした時点で永続的なクリア印を保存する。第1面では右の安全な足場への着地が確定点で、演出や帰還の完了までは待たない。巻物の数からクリアを推測しない。保存に失敗した場合はダイアログで知らせ、確定済みの記録を壊さない。

第1面は3レイヤーのクリア画面から決定で選択へ戻る。ステージ2〜5は既存のクリア通知と練習継続を維持する。再プレイ・死亡・やり直し・スキップ・再起動で記録は消さず、「はじめから」で全て初期化する。

旧第1面の8本の巻物IDは引き継がない。新しい `castle_summit_01` を使い、総数は1。「つづきから」ではステージ2〜5の巻物と設定を保持する。旧第1面だけの保存でも「つづきから」を有効にする。旧版に永続クリアはないため、過去のクリアを収集数から推定しない。

## 保存先と確認

`scripts/collection_progress.gd` は `user://collection_progress.cfg` に形式バージョン2・開始済み・面ごとのクリアと巻物を保存する。一時ファイルの作成と置換に成功してからメモリへ反映する。操作は `input_settings.cfg`、表示は `display_settings.cfg` に保存する。

`tests/game_progress_test.gd` は、開始・再読込・クリア・収集、旧記録の移行、全初期化、保存失敗時の復元、実タイトルのキャンセル・確認・つづきからを確認する。既存の巻物テストも新IDと総数へ更新した。[実行方法と結果](tutorial-stage-1-implementation.md)。
