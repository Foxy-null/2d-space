# ゲーム進行・はじめから・つづきから

状態：実装済み。2026-11-01。Q26・Q27・Q31〜Q33・Q35・Q37を反映。新規開始時は操作設定を初期化し、画面設定は保持する。テストでは使い捨ての保存先を使い、実際のプレイデータは変更していない。

## タイトルと再開

| 項目 | 挙動 |
| --- | --- |
| はじめから | 全進捗と操作設定を初期化し、画面設定を保って第1面へ直接入る |
| つづきから | クリア印・巻物を保持してステージ選択へ入る。保存がなければ無効 |

新規開始時に未クリア・未収集でも開始済み保存を作り、その後は再開できる。全6面は最初から自由に選べる。部屋や途中のチェックポイントは保存せず、面を選び直すと最初から始まる。ステージ6には巻物がなく、三つの勝利条件のどれかを達成するとクリア印を保存する。

タイトルと選択の背景は、第1面の開始地点と共有する。背景表示やメニュー操作だけでプレイ・収集・進捗更新を発生させない。

## 全初期化

全6面のクリア印、巻物、プレイ中の状態、キーボード・マウス・ゲームパッド配置を初期化する。全画面状態とウィンドウサイズは保持し、画面設定の保存ファイルも変更しない。

既存の進捗または変更済み操作設定がある場合だけ確認を表示する。「初期化してはじめる」で実行し、「戻る」では何も消さない。初回で消すデータがない場合は、画面設定を変更していても確認しない。

進捗と操作設定の2つの保存ファイルとメモリを退避してから初期化し、途中の保存に失敗した場合は元へ戻してエラーを表示する。画面設定は成功・失敗のどちらでも変更しない。確認を開いただけでは初期化を呼ばない。

## クリアと移行

最終条件を満たした時点で永続的なクリア印を保存する。第1面では右の安全な足場への着地が確定点で、演出や帰還の完了までは待たない。巻物の数からクリアを推測しない。保存に失敗した場合はダイアログで知らせ、確定済みの記録を壊さない。

第1面は3レイヤーのクリア画面から決定で選択へ戻る。第2面もロケットへの乗り込み後の3層クリア画面から決定で選択へ戻る。ステージ3〜5は既存のクリア通知と練習継続を維持する。再プレイ・死亡・やり直し・スキップ・再起動で記録は消さず、「はじめから」で全て初期化する。

旧第1面の8本の巻物IDは引き継がない。新しい `castle_summit_01` を使い、総数は1。「つづきから」ではステージ2〜5の巻物と設定を保持する。旧第1面だけの保存でも「つづきから」を有効にする。旧版に永続クリアはないため、過去のクリアを収集数から推定しない。

旧第2面の34区間・巻物8本も、新しい10室・巻物4本へ置き換える。バージョン3より前の第2面の巻物とクリア印は引き継がず、新コースで得た記録は以降の再読込で保つ。他ステージと設定は変更しない。

## 保存先と確認

`scripts/collection_progress.gd` は `user://collection_progress.cfg` に形式バージョン3・開始済み・面ごとのクリアと巻物を保存する。一時ファイルの作成と置換に成功してからメモリへ反映する。操作は `input_settings.cfg`、表示は `display_settings.cfg` に保存する。

`tests/game_progress_test.gd` は、開始・再読込・クリア・収集、旧記録の移行、進捗・操作設定の初期化、保存失敗時の復元、実タイトルのキャンセル・確認・つづきから、画面設定の保持を確認する。描画ありの独立ウィンドウでは、全画面のままの開始と、解除後のサイズ復元も確認する。既存の巻物テストも新IDと総数へ更新した。[実行方法と結果](tutorial-stage-1-implementation.md)。
