# 回廊の広い運搬3室

[Issue #142](https://github.com/Foxy-null/2d-space/issues/142)。既存15室の地形を保ち、第16〜18室を幅1920pxで追加する。共通Player・ギミック物理は変えない。開始時のWeekly残量は2026-10-25 11:05 UTCに75%、リセット予定は11月1日06:17:29 UTC。全体の目標時間は未達のまま、内容を増やす。

| 室 | 固有の課題 | 休憩・任意枝 |
| --- | --- | --- |
| 16：空中でダッシュを継ぐ | 相棒を持ち、空中のDash回復から再Dashして660px上の台へ。左上から右へ高さの違う足場を渡る | 最初の広い台で休める。左上の巻物へ寄り、同じ主経路へ戻る |
| 17：反転中の二つの天井 | Upから天井側へ入り、低い方の天井へ反転Jumpと相棒Jump・Dashで渡る。Downから床へ戻り左右に進む | それぞれの天井と床で静止できる。出口は反転した下面着地に使わない |
| 18：風から壁の頂へ | 高い横風で島へ。壁の下を歩いて対向壁の間へ入り、保持した壁キックで登る | 島と壁の頂上が静止床。壁の左上の任意巻物から同じ頂上へ戻る |

新しい部屋だけを横へ広げ、部屋の実原点と幅から境界・復帰・横カメラを求める。旧15室の原点は保つ。最終Goalだけを第18室へ移し、保持条件と死亡時の相棒/アイテム復元は維持する。新2巻物を含む実配置総数は5個。既存3IDと他ステージの記録は保つ。

最初のDash回復は上方の台と同じ画面で見せ、説明ラベルを増やさない。狙うギミックの省略は地形の高低差と隙間で比較する。相棒の背からの踏切など、実際の物理を使う別解は別に検証し、単に想定順を外れたという理由で履歴ロックを足さない。

成功経路10〜20秒を目安、原則30秒以内。通常と実横入力0.8、16/20/24フレームの時機、3秒の静止後の再出発、カメラ/実死/R/最終Goalを確認する。巻物は未確定の中断と実床での確定、元の経路への帰還、保存/別プロセス再読込と選択・読み上げ用の数まで確認する。全18室の通しと旧3巻物、共通クリア/選択/部屋転送も対象とする。配置と数値は以下の実入力で調整した。


## 配置を調整した根拠

第16室では相棒を実際に回復列の下へ運んで置き、その背からGrabと通常Jumpを同時に行うと、相棒Jumpなし・Dash2回で最初の台へ届いた。初Dash16f・再Dash28fの上方向入力で、実床への着地を再現した。最初の台を40px上げて入口との高低差を660pxとし、正規入力は回復後の再Dashを急がず、最初の上昇が緩む28f後に入力する。自由な相棒の移動・投げ・踏み台という基本操作は変更しない。

第17室の後半の足場は、反転天井の下面にプレイヤーが挟まらない高さへ下げた。二つ目の天井を左へ伸ばす案は降下中に上面へ衝突したため採用せず、最初の天井の右端x650から踏み切る。第18室の風と最初の台は通常・弱入力の16/20/24fでも着地できる範囲へ広げ、元の右端は保った。上層の巻物からは左の壁の上へ通常Jumpで戻り、そこから右の主経路の壁へ移れる。


## 実入力と保存の確認

Godot 4.7.2、固定60fps。最終の `tests/corridor_wide_route_test.gd` は8,173項目が成功した（従来207項目に、第17室の全物理フレームの実体・相棒とHUDの観測を追加）。通常20fと実axis0.8の16/20/24fで新3室を通り、3秒静止から再出発して実Goalまたは次室へ到達する。通常転送以外の復帰はない。16/20/24fは離散的な代表入力であり、連続する全時機への保証とは扱わない。

| 第17室 | 15.43秒 | 16.95秒 |
| 第18室 | 11.63秒 | 12.13〜12.25秒 |
| 第16室の巻物往復 | 12.70秒 | 13.30秒 |

新2巻物は通常・0.8で、未確定R・実移動による死亡・途中帰還、実床での確定、3秒の静止、主経路と実出口への帰還、確定後R・死亡・再入場、保存・選択数・読み上げを確認した。空中Dash回復中のRによるアイテム・相棒・資源の復元も実取得で確認する。別プロセスの `tests/corridor_wide_reload_test.gd` も5項目が成功し、実取得した新2ID、選択の2 / 5と読み上げ、再起動後の薄い再訪巻物を確認した。

## 狙うギミックを省く比較

`tests/corridor_wide_required_test.gd` は1,489項目・360代表経路が成功した。回復を止める比較、相棒Jumpなし、初期位置・運んで置き直した相棒への実支持からの同時Grab/Jump、初Dash16/28/40fと再Dash12/28/40f・8方向、Up・Down・風・壁キックの省略を調べる。相棒Jumpを省いた経路には実際にCrystalを取得した30経路も含む。

壁の比較は実際の風で休憩台へ着いてから始め、Downの比較も実際に反転した二つ目の天井から始める。無効化した風やゲートは次の比較へ持ち越さず、新しいステージで開始する。これらは有限の代表入力の結果であり、任意の入力列の不可能証明とはしない。

`tests/corridor_throw_climb_test.gd --wide-shaft` は43項目・12経路が成功した。風を使って実際に島へ着いた後、直接・運んで置いた相棒の背からの踏切、左右の壁、0/4/8fでの実上投げから手ぶらで登り直して再取得を試す。12経路全てで実際の空手の壁登りが成立したが、相棒を保持した高い壁上へは届かなかった。壁キックや自由な投げる操作を共通物理から削除して解決していない。

## 描画とカメラ

描画の予備確認で、第16室の最初の休憩中に巻物がHUDへ重なり、第17室では反転した最初の天井から次の天井が画面下へ隠れていた。第16室のHUDをy80へ移し、第17室は反転中だけカメラを下へ120px寄せ、次の天井の着地面を静止中から見せる。休憩時の巻物とHUDの非交差、次の反転着地面の画面内とHUD非交差も自動検査する。第18室は既存の右下HUDを使い、入口の高い風と上層の巻物・足場を隠さない。独立レビューで第17室の初回Up上昇中に主人公が上HUDへ43〜44フレーム隠れる問題が再現したため、この室だけHUDを左下のx180・y620へ移した。入口の復帰表示、右の次天井、Downと帰路床も隠さない位置を実描画で確認し、上昇中の画像も残す。通常攻略を監視するフレーム検査は正例の_runでだけ有効にし、継承先のギミックを止めて落下する負例では適用しない。

第16室は最初の高い回復列を見せる間だけ上方を広く取り、y1300より上では通常の縦視野へ戻す。巻物の棚で止まった時にも下の主経路の帰り先が画面へ収まる。両新枝の休憩後に、帰り先の着地面が画面内でHUDに隠れないことを実座標で確認する。

初回の描画付き攻略は58項目が成功し、入口・休憩・反転天井・風・巻物・帰路・実GoalのPNG18枚を撮り直して目視した。第16室の巻物棚からも下の帰り床の全幅が見え、HUDに隠れないことを原寸で確認した。

## 既存経路との接続

全18室の `tests/stage_4_test.gd` は859項目が成功し、旧15室から実Goal、全室の運搬条件と天井・復帰、ポーズ帰還・再入場を確認した。旧第10〜15室と旧3巻物を通す `tests/corridor_more_test.gd` は257項目、実保存を使う別プロセスの `tests/corridor_more_reload_test.gd` も5項目が成功した。旧最終室からは第16室へ自然に転送し、旧3IDを読み直した選択画面は3 / 5と読み上げる。

旧第7〜9室と巻物の `tests/corridor_expansion_test.gd` は422項目が成功した。旧第14室の `--new-shaft` 比較も37項目・12経路、旧第8室も73項目・24経路が成功した。いずれも全経路で実際に手ぶらの壁登りを行い、壁キックの代用を再現しなかった。

共通のクリア71・選択144・到着台表示388・未確定巻物の通常部屋転送48項目も最終配置で成功した。独立レビュー後の第17室のHUD修正は、native描画1,864項目で入口・上昇・二つの天井・帰路を確認し、影響する3画像を更新、上昇中1画像を追加した。選択画像を除く最終の記録は17枚。描画のV-Sync非対応の警告以外に、この最終実行の警告はない。

独立レビューで、相棒を移動して背に乗る踏切とDown省略の138代表経路682項目、新対向壁の上投げ12経路43項目を再確認した。相棒Jumpを省いた最良の踏切も、最初の台の上面より足裏が約2.4px下に留まった。有限の踏切位置・時機の結果で、あらゆる連続入力の不可能を保証しない。

本編9〜15分・巻物込み15〜24分の全体目標は未達である。実機パッドと初見の手動試遊は未確認であり、自動入力の成功時間を初見プレイ時間とは扱わない。
