# 重力22〜25室：傘と反転した風（Issue148）

旧21室の座標・地形・巻物IDを保ち、横にnative4室を足す。共有Player、傘、風、ゲートの物理は変更しない。上昇気流は現在の重力に逆らう風を指すため、反転中は画面下向きになる。

|室|主経路|静止休憩・任意枝|
|---|---|---|
|22|通常重力で傘を持って上昇気流へ入り、高い床へ横移動。↑を通って天井へ着き、右へ滑空して↓から着地する。|高い床と天井に広い休憩。上昇途中から左上へ1巻物、同じ風へ自然に戻す。|
|23|入口で↑へ反転して天井へ着く。画面下向きの上昇気流で深い天井足場へ降り、左へ折り返して↓から到着。|上下が反転しても静止支持面を用意。到着後に床を開いて右出口へつなぐ。|
|24|右入口から左上へ傘で上昇して休憩し、↑から左の天井へ移る。反転中の下Dashを空中で回復し、深い↓から左の到着台へ。|上昇と下降Dashを別課題として観察できる棚。左上の任意1巻物と同じ休憩へ帰路。|

寸法と風・回復位置は実入力で調整する。目標は繰り返し成功10〜20秒、上限30秒、待機や無駄な直線を量の根拠にしない。新しい説明ラベルや操作履歴による開錠を加えない。未達や不合格実行を通過件数に含めない。

## 最初に定めた検証範囲

通常／実axis0.8、操作間隔16・20・24frame、必要ギミック省略と有限な踏み台・持込・外壁の比較、R／実落下からの再攻略、旧21↔22・新室左戻り・最終到着、巻物の未確定取消／確定／再訪／別process／選択表示を確認する。native描画の短い分割PNGを全て目視し、傘本体・次の足場・ゲートとHUDの重なりを調べる。

9〜15分という全体目標はこの4室だけでは保証しない。実経路の所要時間と有限比較の範囲を以下に記録する。


## 配置と帰路

第22〜24室は幅2304px、第25室は3072px。第22・24室の入口床はY=1680、第23室はY=1100、第25室はY=1280にある。高さ・幅を広げてもチェックポイントは各室の入口で、到着後はその室の安全な帰り橋を開く。旧第21室は新第22室につながり、この節の実装時は第25室が本編の最終室だった。現在は[第26〜31室](gravity-fifth.md)を追加し、第25室の到着台から第26室へ進む。以下の25室時点の検証件数は当時の実績として残す。

- 第22室：通常の上昇気流からY=900の床、↑から下面Y=600の天井、右の↓とY=900の到着台。
- 第23室：右の入口で↑、下面Y=300の天井で観察してから、下向きの上昇気流で下面Y=900の休憩へ。左の↓からX=800の到着台を押し、開いた床で右へ帰る。下部の隔壁と両面の見えるトゲが、入口から低いままDownへ直接進む経路を閉じる。
- 第24室：右の上昇気流からY=900の床、左の↑から下面Y=650の天井。X=1100の下Dash・Y=950のCrystal・下DashからY=1250の↓へ。X=700の到着台を押し、右へ帰る。
- 第25室：Y=700の床から↑、下面Y=450の天井、反転した上昇気流から下面Y=1000の天井。X=1880・Y=1340の回復Crystalで下Dashをつなぎ、Y=1600の↓からX=2500・Y=1800の到着台へ進む。

第22室の`parachute_loft_07`は左上（240,650）と専用の静止床Y=850を使い、同じ風へ跳んで主経路の床へ戻る。第24室の`folded_current_08`は左上（1600,540）へ外れ、そのままY=900の主経路の床へ着く。入口の印は従来の小さな巻物マークだけで、必須経路では拾わない。到着後も風と巻物の足場を残す。

保持中の傘は90px幅あり、反転中は画面下へ広がる。新室だけ横カメラの端に72pxの余白を持たせ、反転した静止面や下向きの浮上中には縦の先読みを240pxへ滑らかに動かす。通常時・上向きの落下中・Dash中は−80pxへ戻す。反転した下Dashから通常重力へ戻る前に先読みを戻し、ヒントを表示して見出しが横に伸びていても傘を隠さない。第23室の下側カメラ範囲は1400pxまで広げ、右入口で反転した直後の傘もHUDの外に収める。共有PlayerとHUDは変更しない。

## 実際に再現して修正した迂回

第24室では、↑へ入ってすぐ下Dashで通常休憩の下面へ回り、実着地でDashを再補充してから斜め下Dashすると、Crystal0回・死亡0で到着できた。その下面だけを静止したトゲで塞ぎ、到着後に撤去する。第25室では、最初の風から高い床へ向かわず低いまま右へDashすると、重力反転0回・Crystal0回・死亡0で最終到着できた。高い床の下を隔壁と両面の静止トゲで閉じた。

正式なnative strip設定に直した後の再現回帰は2例・8項目を通過し、各経路が対象の`player_hit`を実際に1回発生させた。第22・24・25室の床上の実物Parachuteに着地し、同時Grab/Jumpから8方向Dashする比較は24例・11,124項目を通過した。全例で当該RigidBodyからの実支持を確認しており、位置・速度・Dash残数の注入は行わない。風だけを無効にした比較fixtureで、踏み台が上昇気流を代用しないことを確認する。全入力の不可能証明ではない。

## 共通経路と残る範囲

終了時のObjectDB警告が出る実行では、`--verbose`で`AudioStreamWAV`1個と`AudioStreamPlaybackWAV`1個を確認した。以前の塔・チュートリアルの終了時警告と同じ種類で、今回共有の音声実装は変更していない。終了コードは0で、ゲーム中の蓄積を測る音声反復試験は今回の範囲に含めない。描画のVSync警告も含め、無警告だったとは扱わない。

任意の全入力列・すべての弱入力値の不可能証明、初見プレイヤーによる9〜15分の所要時間調査は未実施。地形による必須化は、実際に見つけた迂回と記載した有限比較に対する結果である。独立レビューとPR統合後に、この拡張を完了として扱う。
