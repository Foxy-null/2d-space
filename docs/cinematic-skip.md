# 全ステージ共通の演出スキップ

状態：実装済み。2026-10-30。Q11・Q13・Q25の承認済み仕様を反映。[第1面の仕様](tutorial-stage-1-redesign.md)と併せて扱う。

## 操作の入口と対象

Escまたはゲームパッドのポーズ操作でメニューを開き、「演出をスキップ」を選ぶ。項目は省略可能な映像演出中だけ表示する。メニューはマウス・キー・パッドで操作できる。演出画面上の直接ボタンや、Enter/Yなどによる直接スキップは設けない。

| 場面 | スキップ後 |
| --- | --- |
| 第1面の橋の減速 | 完全停止したダッシュ入力待ち |
| 暗転とクリア画面の登場 | クリア画面を表示し、新たな決定を待つ |
| 必須のダッシュ入力待ち | 省略不可 |
| ダッシュ・着地・通常攻略・短い部屋切替 | 省略不可 |

同じ押下で次の入力待ちや決定まで実行しない。停止前のダッシュ押しっぱなしでも成功にせず、停止後の押し直しを求める。既存のタイトル登場演出と、新しい登場映像を全ステージに作ることは今回の対象外。

## 停止と取消

メニューと操作設定を開いたら演出も止める。閉じると直前の状態へ戻し、元が完全停止なら停止を維持する。やり直し・離脱では演出を取り消し、時間と操作状態を復元する。クリア条件を満たす前の離脱はクリアにしない。着地後のクリア記録はスキップや帰還で消さない。

## 実装と確認

共通の `scripts/pause_menu.gd` は、ステージの `can_skip_cinematic()` が真の間だけ項目を表示し、選択すると `skip_cinematic()` を呼ぶ。現在の対象は第1面の減速とクリア暗転・登場。ステージ2〜5の開始には映像演出がなく、既存のクリア通知も即表示なので、項目は出ない。

第1面の減速を省略した場合は、忍者と橋を減速終了時と同じ状態へ進めて完全停止する。ポーズの `was_paused` と、既存の操作設定の停止復元で、入力待ちを勝手に解除しない。

`tests/tutorial_redesign_test.gd` で、自然な減速とEsc→方向キー→決定によるスキップの両方を確認する。必須入力の非スキップ、押しっぱなし、設定変更、停止復元、やり直し、クリア画面の新たな決定も検証する。共通メニューは `pause_menu_test.gd` と `input_settings_pause_test.gd` でも確認する。[実行方法と結果](tutorial-stage-1-implementation.md)。

理由は [ADR-0001](adr/0001-cinematic-skip-preserves-required-input.md)に記録した。
