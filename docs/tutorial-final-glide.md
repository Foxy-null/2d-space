# 第16室：滑空・風・重力の連携

Issue #94。Playerの基本能力を変えず、入口から上昇風へ傘を持ち込み、Upゲートで天井に移ってからDownゲートの到着場へ渡る短い連携を作る。

## 変更の根拠

旧配置では、傘を後ろへ置き、実Upゲートで反転した後に通常ジャンプ、36フレーム後の斜め下Dashだけで出口足場へ着地できた。到着台の3つの履歴条件だけがクリアを止めていた。

1280pxの試作では、風を0にしても、自由な傘へ通常ジャンプで乗り、同時Grab＋Jumpの4フレーム後から右へ進み、20フレーム後に上Dashすると、屋根上からUpゲートへ入って出口へ渡れた。傘は幅90pxの実際の踏み台になる。この再現を受けて、部屋だけを横1600pxへ広げ、傘を入口端まで実運搬して置く場合も検証する。入口では傘の前後を移動でき、掴む前の傘とプレイヤーが重ならない間隔を残す。

独立レビューでは、屋根の左面へ傘を持って跳び、静止Dropしてから上Dashすると、自由な傘が屋根端に支えられ、トゲより高い踏み台になる経路が見つかった。そこでDashを回復し、Grab＋Jumpと上Dashをつなげると、風と両ゲートを使わず到着できた。屋根上のトゲだけでは、物体で覆う迂回を防げない。

天井の当たり判定を下向きの片面へ変更し、正規の上昇・反転休憩を支える下面だけを残した。上から落ちる自由な傘は屋根に乗らず通過するため、屋根端での補充に使えない。共有Player・運搬・投げる仕様は変更しない。

## 配置

座標は第16室内のローカル座標。高さ720pxと入口の復帰地点(72,614)を保つ。

| 配置 | 範囲・役割 |
| --- | --- |
| 入口床 | x0〜240、上面y640。傘は(170,593.4) |
| 上昇風 | x300〜1160、y230〜640。傘を保持して横へ進むだけで持ち上がる |
| 天井 | x340〜1200、下面y560の片面天井。反転後に停止して休め、自由な傘は上面に乗らない |
| 屋根上の固定トゲ | x340〜1200。Playerが上面を通ることを防ぐ。自由物体の補充経路は片面天井で防ぐ |
| Upゲート | (1160,550)、64×60。風に乗る高さで触れる |
| 到着場 | x1420〜1600、上面y640、幅180pxの片面床 |
| Downゲート | (1560,360)、64×880。上下の場外境界も含む帯 |
| 到着台 | (1510,640)。履歴条件なしで実際の接地を受け付ける |

狙う基本経路は、傘＋上昇風、Upでの天井休憩、保持したままの反転滑空、Downでの着地。途中で傘を離す・投げる操作や既習のDashは制限しない。風と傘を使って休憩へ到達した後の応用経路も許容し、反転滑空の履歴そのものは到着条件にしない。

第16室だけはカメラが横へ追従し、中心をx640〜960に制限する。Rでは入口側へ直ちに戻す。第17室の原点は20800へ320px移し、各部屋の境界・カメラは部屋Nodeの位置と幅を参照する。通常幅の他室は固定カメラのまま。

## 検証範囲

`tests/tutorial_final_glide_test.gd` は、通常方向入力、3種類の弱いスティックとさらに弱い横入力、天井での3秒休憩と再出発、ゲート直前の8方向Dash、実R、ゲート接触直後の実R、落下、部屋15→16→17と帰路、実到着での本編完了を検証する。第15室を相棒・空中の靴・両追加ジャンプ・上Dashで実際に抜け、境界復帰で保持物が消えることも確認する。

`tests/tutorial_final_glide_bypass_test.gd` は、傘なし／風の実加速0、通常・コヨーテジャンプ、8方向Dash、遅延入力、地上Dash→Jumpの実Superdash、傘に乗ってから同時Grab＋Jump、入口端へ置いた傘の踏み台を確認する。`--basic`、`--coyote`、`--footstool`、`--walls`で分割実行できる。無限の入力の不可能証明ではなく、実測した典型的な代替入力の回帰である。風を止めた試行では、上昇運動だけでも記録される `wind_lift` を風の実使用の根拠にしない。

`tests/tutorial_final_glide_roof_test.gd` は、レビューで確定した屋根端Dropの4時機と、側面へぶつかる前に止めた5地点×4時機の実Dropを検証する。自由な傘による高い着地・Dash補充・Grab＋JumpからのGoal迂回を再試行し、傘が屋根を通過することと安全復帰も確認する。

隣室の幅に依存していた `tutorial_extension_test.gd` の相対座標を実際の部屋原点へ変更し、ガイドの表示範囲も部屋幅を参照する。基本移動テストと最初の4室専用テストに残る1280pxは、拡張されない対象室の座標なので維持する。

描画付き入力の記録は自動操作の確認であり、人による手動プレイは未実施。

## 実測結果

- 方向キーの通常入力は4.82秒。生スティックx0.85（デッドゾーン後0.7）の3方向は各6.85秒、生x0.70（適用後0.4）は12.05秒。すべてジャンプ・Dashなし、死亡復帰0回。
- 天井で3秒停止してから再発進でき、実到着で本編完了を表示する。
- 風なし／傘なし560試行、遅いコヨーテ312試行、実傘踏み台96試行はUpゲートへ到達せず、計968試行・1392項目を通過した。地上Dash→Jumpのうち実Superdashは86回成立した。さらに壁へ登ろうとする24試行・72項目も到着しない。
- 独立レビューの屋根端Drop回帰は24試行・97項目が成功。自由傘の高い着地とDash補充は0件で、実Dropした傘が屋根と横に重なる状態で当たり判定内から下面より下へ通過する16経路も確認した。片面天井への変更後、既存の実傘踏み台96＋壁24試行・312項目、正規102項目、連続実入力101項目を再確認した。
- ゲート手前3地点の8方向Dashと無Dashの27試行では、到着できた経路は実Up/Down両接触を伴った。無効化による対照実験では、どちらのゲートがなくても通常保持ルートは到着できない。
- 全室ガイド356項目、5〜17室の連続実入力101項目、到着台89項目・到着案内426項目が成功。既存の全室系テストには終了時のObjectDB漏れ警告が残るが、失敗項目はない。
