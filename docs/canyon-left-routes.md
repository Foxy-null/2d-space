# 峡谷の左出口と上下の反射

[Issue #130](https://github.com/Foxy-null/2d-space/issues/130)。既存15室に3室を加え、全18室・72反射へ広げる。第15室の到着台は最終室へ移す。部屋ごとの入口を復帰地点にし、共有PlayerとPinballSpringの物理、反射履歴を問わず出口へ着地できる方針は保つ。

| 部屋 | 主経路 | 休憩と寄り道 |
| --- | --- | --- |
| 16：左へ抜ける反射 | 右の入口から上へ戻り、五つの反射をつないで左へ抜ける。高さ960px | 上側の反射からさらに右上へ寄ると巻物。中央の幅160pxの台へ帰り、左の主経路へ戻る |
| 17：上層への五段 | 下の入口から左右へ折り返しながら上層へ登る。高さ1600px | 幅170pxの台で休み、反射へ戻れる |
| 18：深い谷の折り返し | 右上の入口から谷へ降り、下層から左上へ折り返す。高さ1600px | 三つ目の反射から右下へ寄ると巻物。幅170pxの台へ帰り、最後の反射から左の到着台へ向かう |

左出口の部屋では、実際の出口への着地または左境界の通過で次室へ移る。右側は場外復帰の境界になる。出口の矢印と反射番号・経路線は従来どおり任意ヒントに限る。常設の説明文を増やさない。

巻物IDは`canyon/left_sky_02`と`canyon/deep_return_03`。既存の`turning_sky_01`と合わせて3個とし、獲得数を選択画面とアクセシブル名へ反映する。主経路では巻物を取らない。入口の印は小さな巻物の絵だけにし、触れた後は安全な休憩台へ戻ると獲得を確定する。

上昇する部屋はカメラを上寄りに追従させる。第18室は下寄りにし、下降先の反射と休憩台を先に見せる。第17室は状態表示を画面下へ置き、休憩台から見上げる次の反射を隠さない。復帰時は部屋ごとの高さと入口へカメラを戻す。

配置は`scenes/canyon_room_16.tscn`〜`canyon_room_18.tscn`で編集できる。検証は全18室の`tests/stage_5_test.gd`、新室・巻物の`tests/canyon_left_route_test.gd`、既存の巻物を含む`tests/canyon_expansion_route_test.gd`、反射を無効にする`tests/canyon_required_bumper_test.gd`、左右の出口の`tests/stage_5_exit_test.gd`を使う。

Godot 4.7.2 / Linux、物理更新60Hz・固定描画60fpsで、全18室7553項目、新室と巻物224項目、左右の出口105項目が成功した。新3室の成功経路は次のとおり。横入力0.8はソフトウェアの入力強度で、実機パッドの校正結果ではない。

| 部屋 | 通常入力 | 横入力0.8 |
| --- | --- | --- |
| 16 | 7.77秒 | 7.37秒 |
| 17 | 4.77秒 | 7.60秒 |
| 18 | 7.25秒 | 8.08秒 |

巻物から休憩までの往復は第16室で6.17秒／5.37秒、第18室で5.87秒／5.90秒。最初の配置では弱入力で休憩から次の反射へ届かなかったため、最後の反射を低く手前へ移した。修正後は3秒静止してから通常Jumpと残りの反射で主経路へ戻れる。第17室の休憩は、通常Jumpと16・24フレーム後の上Dashで見える2個目の反射へ戻り、上層へ進める。

反射を無効にした新3室の486入力例と、旧第9室の岩壁からの45例は未達で、595項目が成功した。さらに第16・18室の実入口から反射なしで休憩台へ着地し、そこから再ジャンプと8方向Dashを12・20・28フレームで試す54例も出口へ届かなかった。休憩台へ着地できること自体を失敗とは扱わない。任意の入力列に対する不可能証明ではない。既存15室の反射なし一括検証はPR126の2536項目を参照し、今回の全18室の総当たりを完走したとは扱わない。

新しい2個とも未確定のR・実場外死・途中帰還で元へ戻り、確定後は同じ操作でも保存を維持する。選択画面の`1 / 3`・`2 / 3`とアクセシブル名、再読込、薄い再訪表示も確認した。主経路では取らない。

描画付きでも新3室・二つの巻物・休憩後の再開を含む116項目が成功した。

独立レビューでも新室224・全18室7553・左右出口105項目が成功した。追加の90入力では、反射なしで休憩台へ実着地して左端へ歩き、端から14・28・45pxの位置と12・20・28・36・44フレーム後の上／左上／左Dashを組み合わせたが、出口への到達は再現しなかった。必須修正なしと判定した。
