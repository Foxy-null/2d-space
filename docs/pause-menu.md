# ポーズメニュー

状態：要件を確認中。実装前に操作と対象範囲を合意する。

## 確定した要件

- Escでポーズメニューを開く。
- 「ゲームに戻る」「ヒントを表示」「ステージ選択に戻る」を用意する。
- ヒントが用意されていないステージでは、ヒントボタンごと非表示にする。
- ステージ選択に戻る際は「現在の進み具合は保存されません。戻ってもよろしいですか？」という確認画面を表示する。

## 既存の動作

- ステージ1〜4では、プレイ中のEsc・Back／Selectで選択画面に即座に戻る。
- ステージ2〜4にはH・Y／△で開くお助けメニューと、ゲーム画面上のヒントの表示切り替えがある。ステージ1の操作説明・ミッションは常設で、切り替え用のヒントはない。
- お助けメニュー中は主にプレイヤーの操作だけが止まり、物理・ギミック・タイマー・部屋移動などは進む。
- ステージ2・4のお助けメニューには、復帰地点からやり直すボタンもある。R・Startでもやり直せる。
- 全4ステージ共通のクリア表示には、Enter・ゲームパッドA・クリックですぐ選択画面へ戻る入口がある。
- ステージ選択に戻ると進み具合を破棄する。保存・途中再開の機能はない。

参照：[ステージ選択](stage-selection.md)、[ステージ2](stage-2.md)、[ステージ3](stage-3.md)、[ステージ4](stage-4.md)。

## 確認中の判断

1. 対象をステージ1〜4に限定するか、環境プレビュー・開発用デモにも広げるか。
2. ポーズ中は背景を含むゲーム全体を止めるか。
3. 既存の入口を統合し、H・Y／△もポーズの開閉に使うか。
4. ヒントを切り替えた後はポーズを維持するか、ゲームを再開するか。表示中は「ヒントを隠す」に切り替えるか。
5. クリア表示から選択画面に戻る経路でも確認するか。
6. 中央の暗幕付き表示とし、初期フォーカスを再開・確認キャンセルに置くか。Escは確認からポーズ、ポーズからゲームへ戻すか。
7. メニュー内のやり直しボタンを残すか、指定の3項目に統一するか。

## 実装時に確認する点

- クリア表示の入力が、ポーズや帰還確認の入力を先取りしないこと。
- ポーズ中に物体・移動ゲート・復活時間・到着台・部屋移動が進まず、再開後に続きから動くこと。
- 入力の長押しで開閉を繰り返さず、メニュー操作がジャンプ・ダッシュ・やり直しへ伝わらないこと。
- 帰還をキャンセルすると、進み具合を保ったままポーズへ戻れること。
- 選択画面への遷移後やステージへの入り直し後に、ポーズ状態を引き継がないこと。

既存の入力・お助けメニューを前提とするステージ選択、ステージ2〜4、クリア表示のテストと関連仕様書を更新する。
