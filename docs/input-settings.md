# 操作設定

入力設定は `scripts/input_settings.gd` のAutoloadとして独立させている。各ステージが共通のInputMapアクションを使うため、保存した配置はすべてのステージに適用される。

- ステージ選択画面の「操作設定」、またはF10で開く。「タイトルに戻る」から左で設定入口へ、閉じた後は右で元のメニューへ移れる。Tab / Shift+Tabでも往復でき、F10で開いた場合は元の選択へ戻る。ゲーム中は一時停止する。
- キーボードは操作ごとに2枠。クリックしてキーを押すと設定、Escで入力待ちをキャンセル。右クリックで解除。重複配置は許可（既存の上移動と上入力ジャンプの共用など）。
- Esc、F10、F11は画面操作用の予約キー。F11は全画面切替に使う。Escは初期のポーズメニュー操作としても残るが、再割り当てには使用できない。
- 以前の「ヒント表示」と「ステージ選択へ」の個別操作は共通ポーズメニューに統合した。ポーズメニュー内でヒントの切り替えやステージ選択への帰還を選ぶ。
- コントローラーはボタンごとに操作を選択する方式。機種による文字の違いに備えて位置と代表的な表記を併記。左スティックとトリガーの軸割り当ては初期設定を維持する。初期の十字キー上は上移動と上入力ジャンプを共用しているが、変更後は選んだ1操作になる。
- タブごとに初期設定へ戻せる。設定は `user://input_settings.cfg` に自動保存し、次回起動時にも適用する。
- 第1面の壁登り・ダッシュの吹き出しは、最後に使ったデバイスと現在の割り当てを表示する。Sony系は○など、Xbox系はBなど、機種不明はボタン位置で案内する。必要な操作が未割り当てなら設定を開くボタンを表示する。他の既存ステージの説明は初期配置の表記。

ポーズメニューからも「操作設定」を開ける。第1面のダッシュ入力待ちから開いた場合、閉じても世界の完全停止を維持する。「はじめから」の全初期化では、全デバイスの配置も初期設定へ戻す。

以前に保存したF11の割り当ては読み込み時に除外する。その操作のキーボード・マウス割り当てがなくなる場合は、キーボードの初期配置を戻す。全画面切替と表示サイズの記憶は[画面表示](display-settings.md)を参照する。

検証: `Godot_v4.7.2-stable_win64_console.exe --headless --path . --script tests/input_settings_test.gd`
