# 操作設定と今後の統合方針

このブランチの作業時点で、mainではステージ4を別コースに置き換え、ステージ5を追加する予定。今後の変更でも、この更新と干渉しにくい構成を維持すること。

入力設定は `scripts/input_settings.gd` のAutoloadとして独立させている。ステージ、ステージ選択画面、プレイヤーのファイルは変更していない。main統合時は `project.godot` の `[autoload]` にInputSettingsの登録を残す。新ステージも同じInputMapアクションを使う限り保存した配置が適用される。将来mainが別の入力設定機構を導入した場合は統合作業が必要。

- ステージ選択画面の「操作設定」、またはF10で開く。ゲーム中は一時停止する。
- キーボードは操作ごとに2枠。クリックしてキーを押すと設定、Escで入力待ちをキャンセル。右クリックで解除。重複配置は許可（既存の上移動と上入力ジャンプの共用など）。
- EscとF10は画面操作用の予約キー。Escは初期のステージ選択へ戻る操作としても残るが、再割り当てには使用できない。
- コントローラーはボタンごとに操作を選択する方式。機種による文字の違いに備えて位置と代表的な表記を併記。左スティックとトリガーの軸割り当ては初期設定を維持する。初期の十字キー上は上移動と上入力ジャンプを共用しているが、変更後は選んだ1操作になる。
- タブごとに初期設定へ戻せる。設定は `user://input_settings.cfg` に自動保存し、次回起動時にも適用する。
- ゲーム内に元からある操作説明は初期配置の固定表記。設定画面にもその旨を表示する。

検証: `Godot_v4.7.2-stable_win64_console.exe --headless --path . --script tests/input_settings_test.gd`
