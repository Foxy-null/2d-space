# 任意のSuperdash練習路

[Issue #98](https://github.com/Foxy-null/2d-space/issues/98)。チュートリアルは必須16室＋任意の第17室を維持し、地上の水平DashからJumpへつなぐ練習路を地形で作る。共通Playerの速度・ジャンプ・ダッシュ・コヨーテ受付は変更しない。

## 配置と選定理由

従来の第17室は床がつながっており、通常Jump3回でも到着台へ進めた。到着台の操作履歴だけがSuperdashを要求していた。今回は回復床を取り除き、入口床の先を床トゲと100px高い一方通行の着地足場にする。入口側の天井を低く張り出し、着地足場側にも少し高い天井トゲを置く。天井の上端は部屋の上境界より高く、天井上を新しい補充場所にしない。

既存の風ギミックで起こす逆風は入口床の後半から着地足場の前端まで吹く。歩行と通常Jumpの横移動は遅くなり、地上の水平Dashで低い天井の出口へ進み、Jumpで得る水平の勢いを使って段上へ渡れる。通常の空中DashはJumpに切り替えられず、上向きのDashは低い天井のトゲに触れる。単に穴を広げる案では空中DashがSuperdashより遠くへ進めるため、採用しなかった。

到着台は最初から押せる状態にし、`STEPS[16]`とSuperdash専用の進捗ラベルを空にする。足場の側面は一方通行なので、壁登りの足掛かりを増やさない。既存の操作案内1行を残し、場内の重複するボタン案内と到着ラベルを削除する。

到着後もRで同じ入口へ戻れ、完了状態を保持したまま左から第16室へ退出できる。第17室のクリアやSuperdashの実行は本編の完了条件に含めない。到着台からトゲのある練習路をそのまま左へ歩く復路は設けていない。

## 検証

`tests/tutorial_superdash_terrain_test.gd`は実入口から移動し、Playerの座標・能力・物理を差し替えずに確認する。各試行で完成した到着台を再利用せず、正例の次は新しいSceneを作る。

- 通常入力と実JoypadMotionの0.85入力（既存deadzone後の横入力0.7）、3つの踏切位置、3つのJump遅延（Dash入力後3・5・7フレーム）を組み合わせた18経路。実Superdashの発生、実到着台の押下、死亡なし、入口から30秒以内を確認する。通常入力は4.23〜6.60秒、raw0.85は5.90〜9.30秒だった。
- 通常Jumpと8方向空中Dash192経路、地上の8方向Dashと低い天井にぶつかった後のJump104経路、自然に端から外れた後のコヨーテ入力128経路、Grab・壁登り・壁キック・外壁からの入力16経路の計440負例を確認する。到着台の未押下に加え、着地足場を物理的に踏んでいないことも監視する。
- 床トゲへの実際の落下、飛行中の実Rキー、完了後の再開、本編の実到着と第16↔17室の境界移動を確認する。飛行中に実接触したネイティブ巻物の試験fixtureは、Rで原位置へ戻り、保存されないことも確認する。試験の保存先はPID付きの専用ファイルへ分離する。

負例は有限の代表入力であり、任意の操作列に対する数学的な不可能の証明ではない。遅いコヨーテ入力など、Dashを押す前にトゲへ触れる試行も含む。実機ゲームパッドと初見プレイヤーによる操作感、60Hz以外の入力幅は未確認。

```sh
godot --headless --path . --fixed-fps 60 --quit-after 350000 --script res://tests/tutorial_superdash_terrain_test.gd
```

`-- --routes-only`で正例と往復だけを確認できる。`-- --screenshots`は描画環境で実攻略を通し、`docs/screenshots/tutorial-superdash/`へ入口・飛行・到着を保存する。

最終の正例・本編完了・到着後R・第16↔17室の往復は97項目、未確定巻物を含む再開と往復の追加確認は17項目が成功した。440負例は到達しなかった。さらに、地上Dashで回復した後にSuperdash受付が切れるのを待ち、通常Jumpから2回目の空中Dashを使う36経路・37項目も到達しなかった（計476負例）。全36経路で実際の地上回復を確認した。遅いJumpの発火確認を入力直後に置いた旧試験は4件失敗したため、既存のJumpバッファがDash終了時に消費されるまで待って観測する位置へ修正し、正例18経路を再実行した。

既存の第5〜17室の経路は101項目、表示・ヒントは354項目、Xvfb/OpenGLの実攻略は8項目が成功した。入口・Superdash中・到着後のPNG3枚を目視し、足場とトゲ、逆風、Playerの位置が読み取れることを確認した。表示試験の終了時ObjectDB警告はmainの6個から4個へ減り、後半経路は既知と同様の2個だった。専用の正例・巻物再開・描画はObjectDB警告なし。音声処理は変更していない。
