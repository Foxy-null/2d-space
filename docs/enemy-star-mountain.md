# 星間山荒・大赤斑

ステージ6の追跡敵1体に、ユーザー提供の姿勢6枚と針2枚を割り当てる。総称は「UMA妖怪エイリアン」、個体名は「星間山荒・大赤斑」。作業先は `feat/stage6-enemy-assets-and-chase`。mainへのコミット・マージ・pushはしない。

## 素材と表示

原本・対応表・画像補正のプロンプトは [素材の記録](../assets/enemies/star-mountain/PROMPTS.md) に保存した。透明穴1画素のみを補正し、白い模様と描線は保持した。補正前後は `deliverables/enemy-comparison.png`、姿勢と忍者との大きさの比較は `deliverables/enemy-poses.png` で確認する。

通常の姿勢は見た目の高さ96pxで、忍者52pxの約1.85倍。姿勢ごとの透明余白を除き、縦横比と足元を揃え、毛の広がりに引っ張られないよう胴体の表示位置を調整する。歩行A/Bを速度に合わせて切り替える。既存コースを通れる物理本体36×52pxは維持し、長い毛や頭上の装飾は接触判定に含めない。

下降速度が重力方向へ45〜500px/sのときは下降画像。それ以上の速い落下はジャンプ画像を左へ45度傾ける。4方向の重力と左右向きにも対応する。やられ画像は怯みと決着に使い、横倒しの姿勢なので高さ58pxとする。保持中は腕を上げた下降画像を再使用し、新しい姿勢は描き足さない。

## 針の攻撃と地形

荷物を持っておらず、敵からプレイヤーが見える距離130〜700pxで針攻撃を始める。長針1本の直線狙いと、短針3本の扇状発射を交互に使う。予告はそれぞれ0.8秒と1秒で、狙いは予告開始時に固定する。発射後は0.65秒追跡を休み、次の針まで3秒空ける。怯ませると予告を中断できる。

飛行は連続した線分で判定し、壁越しに当たらない。飛行中の先端に当たると、既存の投擲と同じくスタミナが最大値の3分の1減り、0.3秒怯む。地形に刺さった針は時間で消えず、露出した先端の周囲3pxだけがトゲになる。軸には危険判定を置かない。

刺さった針へ軽い箱または重い箱を投げると、先端を箱の中へ埋めて固定する。箱は実際の物理的な足場になり、先端を覆って安全に通れる。固定後の箱は掴めず、敵や物体供給の回収対象にもならない。傘・生物は固定しない。空中で箱に当たった針は箱に遮られ、空中へ固定足場を作らない。

部屋1・6・10の任意経路に、色とひびで区別した壊れる足場を追加した。長針を誘導して壊せる。短針は通常どおり刺さる。支えが壊れた針は取り除き、その針に固定されていた箱は落下する。

落下やトゲでプレイヤーだけが復帰すると、針・固定した箱・壊れた足場は維持する。R / Startまたはメニューで部屋全体をやり直すと、針を除去し、箱と壊れた足場も初期状態へ戻す。部屋移動でも針を含む旧部屋全体を解放する。1部屋96本を上限に針の追加を止め、既存の針や足場を勝手に消さない。

決着・封じ込め・逃走の3つの勝利条件は変更しない。Escの共通ポーズと帰還確認に対応し、H / Y・△ではステージ6の攻略説明を開ける。

## 検証

Godot 4.7.2で、既存のステージ6の勝利条件138項目、実追跡9項目、新しい針・足場・姿勢の43項目を検証する。針のテストは次のコマンドで実行する。

```sh
godot --headless --fixed-fps 60 --path . --script res://tests/stage_6_needles_test.gd
```

`tests/star_mountain_visual_review.gd` は描画ありで比較画像を作り、`-- --movie` を付けると実際の針の壁衝突・箱の投擲・固定・箱への着地を確認するデモを実行する。デモの初期位置は確認用に設定し、最終戦の攻略動画とは扱わない。

針を含む全12部屋の入力再生、既存の移動・運搬・環境・忍者の表示・ステージ5・メニュー・クリア画面も回帰確認する。人が遊んだ際の楽しさ、初回攻略時間、実機ゲームパッドでの操作感は未評価で、次の試遊で調整する。
