# 星間山荒・大赤斑

ステージ6の追跡敵1体に、ユーザー提供の姿勢13枚と攻撃原画6枚を割り当てる。総称は「UMA妖怪エイリアン」、個体名は「星間山荒・大赤斑」。当初の実装先は `feat/hikariyamaseistage6overhaul`、現在の調整先は `backup/hikariyamaseistage6overhaul-before-update`。mainへのコミット・マージ・pushはしない。

## 素材と表示

原本・対応表・画像補正のプロンプトは [素材の記録](../assets/enemies/star-mountain/PROMPTS.md) に保存した。透明穴1画素のみを補正し、白い模様と描線は保持した。補正前後は `deliverables/enemy-comparison.png`、今回の姿勢と忍者との大きさの比較は `deliverables/star-mountain-update/素材表-01-基本動作.png` と `素材表-02-攻撃とダッシュ.png` で確認する。

通常の立ち姿は見た目の高さ128pxで、忍者52pxの約2.46倍。透明な余白を除いて、縦横比を保つ。`poses.json` の胴体・足元の基準点と換算身長を使い、ダッシュの軌跡や投げ返しの渦まで含めて体を縮めない。コースを通る物理本体36×52pxは維持し、毛や頭上の装飾は接触判定に含めない。

歩行と運搬歩行には、それぞれA/Bの2枚を使用する。地上の運搬歩行を下降の共用姿勢より先に判定する。停止して持つ・空中で持つ・傘の滑空は腕を上げた下降画像を共用。ダッシュ・スーパーダッシュ・壁掴み／壁登り・投擲／投げ返しには追加された専用素材を割り当てた。左の立ちはsozai156をそのまま使用する。壁掴み・壁登りはジャンプ（sozai4）と壁登り（sozai11）の2枚を毎秒6コマで交互に表示する。両素材には同じ換算身長・足元基準を適用する。

下降速度45〜500px/sは下降画像。それ以上の落下はジャンプ画像を左へ45度傾ける。やられ画像は怯みと決着専用。捕獲後の投げ返しは、演出のために入る敵の短い怯みより優先して表示する。4方向の重力と左右向きにも対応する。

## 針の攻撃と地形

敵は視認した位置・速度を使って距離と行動に合う技を選ぶ。600pxより遠くでは灰雲を優先し、山なりの長針、追尾、連射も技別の待ち時間に応じて使う。連射は観測位置へ毎発狙い直し、旋回量を制限する。空中・運搬中も移動を続けて技を使える。壁で見失った場合、現在位置を盗み見せず最後の観測だけを使用し、2秒以上見失ったら新しい攻撃を始めない。

| 技 | 弾数と動き | 予告 |
| --- | --- | --- |
| 長針 | 3本、0.2秒間隔 | 0.8秒 |
| 扇形 | 5本、約14度間隔 | 0.8秒 |
| 追尾トゲ | 同時6発、約86度の扇状に発射してから追尾 | 1.1秒 |
| 灰の雨 | 8波、5本と4本を交互に計36本 | 1.1秒＋雲の形成1.3秒 |
| 山なりの長針 | 10本、異なる落下位置へ弾道飛行 | 1.1秒 |
| 短針連射 | 18本、0.08秒間隔、1発につき最大0.18rad照準を追従 | 0.8秒 |

予告・連射・発射後0.75秒の硬直中は捕獲できない。全体の待ち時間は1.8秒。技別の待ち時間は順に3.5／4／7／7.5／6／5秒。追尾弾と灰雲を重ねず、物体投げもこれらと重ねない。怯みや重力変更で予告を中断する。

飛行は連続した線分で判定し、壁越しに当たらない。飛行中の先端に当たると、既存の投擲と同じくスタミナが最大値の3分の1減り、0.2秒怯む。0.75秒の連続被弾と捕獲の猶予を付ける。地形に刺さった針は着弾の角度を保ち、露出した先端の周囲3pxだけがトゲになる。軸には危険判定を置かない。残針の先端は最大スタミナの15%減と1秒の走行速度30%低下とし、即座に入口へ戻さない。飛行弾・投擲・残針の実際の被弾で回復低下4秒、追加被弾ごとに2秒延長し最大8秒。通常時の着地は即時全回復、回復低下中は最大値の10%/秒で回復する。攻撃でスタミナが0になると、残針が最後の一撃でもゲームオーバー演出後に現在の部屋のチェックポイントから自動で再開する。捕獲ではスタミナが少しでも残っていれば必ずしのぎ、失敗抽選は行わない。スタミナ0での捕獲も同じ復帰処理を使い、スタミナと状態異常、敵と部屋の状態を初期化する。

刺さった針へ軽い箱または重い箱を投げると、先端を箱の中へ埋めて固定する。箱は実際の物理的な足場になり、先端を覆って安全に通れる。固定後の箱は掴めず、敵や物体供給の回収対象にもならない。傘・生物は固定しない。空中で箱に当たった針は箱へ刺さり、その移動と回転に追従する。この針は安全で、箱自体は固定しない。保持中の箱も同じ盾になる。開いた傘は上からの弾を消し、地上でも開く。ダッシュ中は傘が閉じる。浅い角度で地形に刺さった針にも箱を固定できるが、忍者と重なる位置へは固定しない。

部屋1・6・10の任意経路に、色とひびで区別した壊れる足場を追加した。長針を誘導して壊せる。短針は通常どおり刺さる。支えが壊れた針は取り除き、その針に固定されていた箱は落下する。

落下や固定・移動トゲでプレイヤーだけが復帰すると、針・固定した箱・壊れた足場は維持する。R / Startまたはメニューで部屋全体をやり直すと、針を除去し、箱と壊れた足場も初期状態へ戻す。ただし被弾状態とその間のスタミナ損失はやり直しでも維持する。部屋移動でも針を含む旧部屋全体を解放する。1部屋640本、同時飛行96本が上限。同じ地形の3px以内へ重なる針は統合し、既存の針や足場を勝手に消さない。上限に達した場合は予告から新しい攻撃を止める。

決着・封じ込め・逃走の詳細は [ステージ6の仕様](stage-6.md) を参照。Escの共通ポーズと帰還確認に対応し、H / Y・△ではステージ6の攻略説明を開ける。

## 追尾トゲ・灰の雨・トゲ耐性

追尾トゲは同じ弾の状態としてc1→c2を使う。発射位置で0.65秒待機し、炎を付けて速度380px/sで飛行。6発の角度は狙いに対して±0.15・±0.45・±0.75radとし、予告の射線にも同じ角度を使う。飛行開始から0.2秒はそれぞれの方向へ直進して広がり、その後に毎秒2.3radで追尾する。追尾は2.5秒で終了して弾が青みがかり、直進へ移る。飛行寿命5秒で消える。地形に刺さると炎を止めてc1へ戻り、長針・短針と同じ先端トゲ・箱の固定処理を使う。

灰の雲は狙った位置から反重力方向へ260pxの場所に作る。屋根が間にあれば屋根の上へ生成し、防御の役割を保つ。灰色の煙が集まって雲となり、黄色い渦を循環させる。形成開始から1.3秒で雨が始まり、0.45秒間隔で8波・計36本（5本と4本を交互）の固まった灰を降らせる。各列の間隔は160px、雲の幅は760pxで、左右に交互の隙間を残す。雲は回避するプレイヤーを追わず、雨は発射時の重力方向へ660px/sで進み、通常地形で遮られる。1部屋に同時1雲、5.7秒で雲が消える。部屋のRリトライでは雨と雲を消す。プレイヤーだけの落下復帰では継続する。

敵はspike_immuneグループに属し、静止・移動トゲ、地形に刺さった針、飛行するトゲ・固まった灰でダメージや復帰を受けない。トゲ地形と刺さった針に敵だけが接触する物理面を付け、トゲの上の歩行・壁掴み・登りに共有の移動処理を使う。忍者と箱の物理マスクはこの面を見ないため、箱を針先へ刺す操作は維持する。敵への箱投げは引き続き有効。

灰雨の刺さった針は8秒、短針連射は5秒で消える。箱が固定された針は維持する。長針・扇形・追尾の固定針も維持する。復帰直後は0.8秒猶予を付け、入口に残った針で動けなくなる反復を防ぐ。
