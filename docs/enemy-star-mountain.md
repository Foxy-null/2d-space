# 星間山荒・大赤斑

ステージ6の追跡敵1体に、ユーザー提供の姿勢13枚と攻撃原画6枚を割り当てる。総称は「UMA妖怪エイリアン」、個体名は「星間山荒・大赤斑」。作業先は `feat/stage6-enemy-assets-and-chase`。mainへのコミット・マージ・pushはしない。

## 素材と表示

原本・対応表・画像補正のプロンプトは [素材の記録](../assets/enemies/star-mountain/PROMPTS.md) に保存した。透明穴1画素のみを補正し、白い模様と描線は保持した。補正前後は `deliverables/enemy-comparison.png`、今回の姿勢と忍者との大きさの比較は `deliverables/star-mountain-update/素材表-01-基本動作.png` と `素材表-02-攻撃とダッシュ.png` で確認する。

通常の立ち姿は見た目の高さ128pxで、忍者52pxの約2.46倍。透明な余白を除いて、縦横比を保つ。`poses.json` の胴体・足元の基準点と換算身長を使い、ダッシュの軌跡や投げ返しの渦まで含めて体を縮めない。コースを通る物理本体36×52pxは維持し、毛や頭上の装飾は接触判定に含めない。

歩行と運搬歩行には、それぞれA/Bの2枚を使用する。地上の運搬歩行を下降の共用姿勢より先に判定する。停止して持つ・空中で持つ・傘の滑空は腕を上げた下降画像を共用。ダッシュ・スーパーダッシュ・壁掴み／壁登り・投擲／投げ返しには追加された専用素材を割り当てた。左の立ちはsozai156をそのまま使用する。壁登りは原画1枚で、手足を交互に描き替えるアニメーションは未提供。

下降速度45〜500px/sは下降画像。それ以上の落下はジャンプ画像を左へ45度傾ける。やられ画像は怯みと決着専用。捕獲後の投げ返しは、演出のために入る敵の短い怯みより優先して表示する。4方向の重力と左右向きにも対応する。

## 針の攻撃と地形

荷物を持っておらず、敵からプレイヤーが見える距離130〜700pxで針攻撃を始める。長針1本、短針3方向、追尾トゲ、灰の雲の順に攻撃する。予告は直線0.8秒、他の攻撃1秒。直線と三方向の狙い・灰の雲の設置位置は予告開始時に固定する。発射後は0.65秒追跡を休み、次の針まで3秒空ける。怯ませると予告を中断できる。

飛行は連続した線分で判定し、壁越しに当たらない。飛行中の先端に当たると、既存の投擲と同じくスタミナが最大値の3分の1減り、0.3秒怯む。地形に刺さった針は時間で消えず、露出した先端の周囲3pxだけがトゲになる。軸には危険判定を置かない。

刺さった針へ軽い箱または重い箱を投げると、先端を箱の中へ埋めて固定する。箱は実際の物理的な足場になり、先端を覆って安全に通れる。固定後の箱は掴めず、敵や物体供給の回収対象にもならない。傘・生物は固定しない。空中で箱に当たった針は箱に遮られ、空中へ固定足場を作らない。

部屋1・6・10の任意経路に、色とひびで区別した壊れる足場を追加した。長針を誘導して壊せる。短針は通常どおり刺さる。支えが壊れた針は取り除き、その針に固定されていた箱は落下する。

落下やトゲでプレイヤーだけが復帰すると、針・固定した箱・壊れた足場は維持する。R / Startまたはメニューで部屋全体をやり直すと、針を除去し、箱と壊れた足場も初期状態へ戻す。部屋移動でも針を含む旧部屋全体を解放する。1部屋96本を上限に針の追加を止め、既存の針や足場を勝手に消さない。

決着・封じ込め・逃走の3つの勝利条件は変更しない。Escの共通ポーズと帰還確認に対応し、H / Y・△ではステージ6の攻略説明を開ける。

## 追尾トゲ・灰の雨・トゲ耐性

追尾トゲは同じ弾の状態としてc1→c2を使う。発射位置で0.65秒待機し、炎を付けて速度380px/sで飛行。旋回速度は毎秒2.3rad、追尾は2.5秒で終了し、飛行寿命5秒で消える。地形に刺さると炎を止めてc1へ戻り、長針・短針と同じ先端トゲ・箱の固定処理を使う。

灰の雲は狙った位置から反重力方向へ260pxの場所に作る。低い天井があれば天井の下へ留める。灰色の煙が集まって雲となり、黄色い渦を循環させる。形成開始から1.8秒で雨が始まり、0.48秒間隔で6波・最大15本の固まった灰を降らせる。各列の間隔は160pxで、左右に交互の隙間を残す。雲は回避するプレイヤーを追わず、雨は発射時の重力方向へ660px/sで進み、通常地形で遮られる。1部屋に同時1雲、5.3秒で雲が消える。部屋のRリトライでは雨と雲を消す。プレイヤーだけの落下復帰では継続する。

敵はspike_immuneグループに属し、静止・移動トゲ、地形に刺さった針、飛行するトゲ・固まった灰でダメージや復帰を受けない。トゲ地形と刺さった針に敵だけが接触する物理面を付け、トゲの上の歩行・壁掴み・登りに共有の移動処理を使う。忍者と箱の物理マスクはこの面を見ないため、箱を針先へ刺す操作は維持する。敵への箱投げは引き続き有効。
