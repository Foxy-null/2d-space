# 星間山荒・大赤斑

ステージ6の追跡敵1体に、ユーザー提供の姿勢13枚と攻撃原画6枚を割り当てる。総称は「UMA妖怪エイリアン」、個体名は「星間山荒・大赤斑」。作業先は `feat/hikariyamaseistage6overhaul`。mainへのコミット・マージ・pushはしない。

## 素材と表示

原本・対応表・画像補正のプロンプトは [素材の記録](../assets/enemies/star-mountain/PROMPTS.md) に保存した。透明穴1画素のみを補正し、白い模様と描線は保持した。補正前後は `deliverables/enemy-comparison.png`、今回の姿勢と忍者との大きさの比較は `deliverables/star-mountain-update/素材表-01-基本動作.png` と `素材表-02-攻撃とダッシュ.png` で確認する。

通常の立ち姿は見た目の高さ128pxで、忍者52pxの約2.46倍。透明な余白を除いて、縦横比を保つ。`poses.json` の胴体・足元の基準点と換算身長を使い、ダッシュの軌跡や投げ返しの渦まで含めて体を縮めない。コースを通る物理本体36×52pxは維持し、毛や頭上の装飾は接触判定に含めない。

歩行と運搬歩行には、それぞれA/Bの2枚を使用する。地上の運搬歩行を下降の共用姿勢より先に判定する。停止して持つ・空中で持つ・傘の滑空は腕を上げた下降画像を共用。ダッシュ・スーパーダッシュ・壁掴み／壁登り・投擲／投げ返しには追加された専用素材を割り当てた。左の立ちはsozai156をそのまま使用する。壁掴み・壁登りはジャンプ（sozai4）と壁登り（sozai11）の2枚を毎秒6コマで交互に表示する。両素材には同じ換算身長・足元基準を適用する。

下降速度45〜500px/sは下降画像。それ以上の落下はジャンプ画像を左へ45度傾ける。やられ画像は怯みと決着専用。捕獲後の投げ返しは、演出のために入る敵の短い怯みより優先して表示する。4方向の重力と左右向きにも対応する。

## 針の攻撃と地形

敵が忍者を視認し、距離130〜700pxで実際の発射口が地形に埋まっていない場合に予告する。直線は長針3本を0.2秒間隔、扇形は5本を約14度間隔で同時発射、追尾トゲは0.5秒間隔で2本。部屋ごとに1〜2種類を組み合わせ、最終戦は全種類を順番に使う。長針・扇形・追尾は原則地上で空身のときに発射する。灰雲は背中から作るため、傘を保持した上昇中にも発動し、移動と保持を続ける。

予告は長針0.8秒、他は1秒。直線・扇形の照準と灰雲の設置位置は予告開始時に固定し、予告線は壁までで止まる。攻撃別の合図音を鳴らす。連射完了後0.65秒は追跡を休み、その後の弾まで3秒空ける。予告・連射・硬直中は捕獲できず、怯みや重力変更で予告を中断する。追尾弾と灰雲の同時使用を避け、物体投げもこれらと重ねない。

飛行は連続した線分で判定し、壁越しに当たらない。飛行中の先端に当たると、既存の投擲と同じくスタミナが最大値の3分の1減り、0.3秒怯む。地形に刺さった針は時間で消えず、露出した先端の周囲3pxだけがトゲになる。軸には危険判定を置かない。

刺さった針へ軽い箱または重い箱を投げると、先端を箱の中へ埋めて固定する。箱は実際の物理的な足場になり、先端を覆って安全に通れる。固定後の箱は掴めず、敵や物体供給の回収対象にもならない。傘・生物は固定しない。空中で箱に当たった針は箱に遮られ、空中へ固定足場を作らない。

部屋1・6・10の任意経路に、色とひびで区別した壊れる足場を追加した。長針を誘導して壊せる。短針は通常どおり刺さる。支えが壊れた針は取り除き、その針に固定されていた箱は落下する。

落下やトゲでプレイヤーだけが復帰すると、針・固定した箱・壊れた足場は維持する。R / Startまたはメニューで部屋全体をやり直すと、針を除去し、箱と壊れた足場も初期状態へ戻す。部屋移動でも針を含む旧部屋全体を解放する。1部屋384本、同時飛行32本が上限。同じ地形の3px以内へ重なる針は統合し、既存の針や足場を勝手に消さない。上限に達した場合は予告から新しい攻撃を止める。

決着・封じ込め・逃走の詳細は [ステージ6の仕様](stage-6.md) を参照。Escの共通ポーズと帰還確認に対応し、H / Y・△ではステージ6の攻略説明を開ける。

## 追尾トゲ・灰の雨・トゲ耐性

追尾トゲは同じ弾の状態としてc1→c2を使う。発射位置で0.65秒待機し、炎を付けて速度380px/sで飛行。旋回速度は毎秒2.3rad、追尾は2.5秒で終了して弾が青みがかり、直進へ移る。飛行寿命5秒で消える。地形に刺さると炎を止めてc1へ戻り、長針・短針と同じ先端トゲ・箱の固定処理を使う。

灰の雲は狙った位置から反重力方向へ260pxの場所に作る。低い天井があれば天井の下へ留める。灰色の煙が集まって雲となり、黄色い渦を循環させる。形成開始から1.8秒で雨が始まり、0.48秒間隔で6波・計21本（4本と3本を交互）の固まった灰を降らせる。各列の間隔は160pxで、左右に交互の隙間を残す。雲は回避するプレイヤーを追わず、雨は発射時の重力方向へ660px/sで進み、通常地形で遮られる。1部屋に同時1雲、5.3秒で雲が消える。部屋のRリトライでは雨と雲を消す。プレイヤーだけの落下復帰では継続する。

敵はspike_immuneグループに属し、静止・移動トゲ、地形に刺さった針、飛行するトゲ・固まった灰でダメージや復帰を受けない。トゲ地形と刺さった針に敵だけが接触する物理面を付け、トゲの上の歩行・壁掴み・登りに共有の移動処理を使う。忍者と箱の物理マスクはこの面を見ないため、箱を針先へ刺す操作は維持する。敵への箱投げは引き続き有効。
