# 押下時間で高さが変わるジャンプ

状態：実装済み。2026-10-30。Q21・Q29・Q34・Q36の承認済み仕様を反映。[第1面の改修仕様](tutorial-stage-1-redesign.md)と併せて扱う。

## 共通の挙動

全5面で、押す長さに応じて連続的に高さが変わる。長押しは従来の最大軌道を保ち、上昇中に離すと低く跳ぶ。着地後に押しっぱなしで自動再ジャンプはしない。

| 移動 | 高さ調整 |
| --- | --- |
| 地上・コヨーテ猶予・先行入力からのジャンプ | 適用 |
| 壁キック | 適用。横方向の蹴り出しは保つ |
| プレイヤーと相棒の追加空中ジャンプ | 適用 |
| ダッシュ後・Superdashのジャンプ | ジャンプ部分に適用 |
| ダッシュ自体・ばね・バンパーの発射 | 適用しない |

通常ボタンと上入力ジャンプの両方に適用し、そのジャンプを始めたアクションで保持を判定する。たとえば上を保持したままSpaceを短押ししても、Spaceで始めたジャンプは短くなる。追加ジャンプでは新しい入力へ切り替える。

0.14秒の先行入力とコヨーテ猶予を維持する。着地直前に押して離した先行入力は、着地時に短いジャンプになる。反転重力では現在の重力と逆方向の上昇に適用する。運搬倍率、風、傘の制限は従来どおり。

## 実装

共通の `scripts/player.gd` で、上昇中のリリース時に上昇速度を一度だけ40%へ落とす。ばね・ダッシュ・壁掴み・重力切替・復帰では前のジャンプの制動を解除する。通常ジャンプ初速650px/s、重力1900px/s²は変えない。

第1面の最初の穴は230px。短押しでは越せず、最高速度と長押しなら越せる。高さ調整の説明文は出さず、地形から理解する構成にした。

## 検証

`tests/variable_jump_test.gd` の60Hz実物理で、短押し29.11px、中間79.91px、長押し116.74pxを確認。長押しは従来の離散物理の最大軌道の範囲を保つ。反転重力、壁キックの高さと横速度、追加ジャンプ、上入力との併用、リリース済み先行入力、ばねと上ダッシュへの非干渉も確認した。

重箱・相棒・SuperdashはPhase 3、風と発射は共通ギミックと各面の攻略テストで確認する。既存の最大ジャンプ経路は、1フレーム押しから `FullJumpInput` による頂点までの保持へ変更した。地形や最大性能は変えず、ステージ2〜5を最後まで通過した。[検証記録](tutorial-stage-1-implementation.md)。
