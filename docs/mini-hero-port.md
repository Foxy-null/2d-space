## 仮実装の内容と理由

次の数値・順序は元の仕様として扱わない。仮処理にはコード内でも理由を記載し、ゲーム内の開発状況画面にも表示している。

### 開始と操作

- 初期SPは各3。素材は各6、薬草4・魔力水3・復活石1。初期装備は勇者が銅の剣・鉄の鎧、魔法使いが見習いの杖・魔導ローブ、僧侶が祈りの杖・修道士の法衣。定義を試せるように仮配置した。
- 味方は勇者→魔法使い→僧侶の順で、生存者が各1回行動すると生存中の敵が行動する。倒れた味方を飛ばし、MP不足・使用不能・不正な対象による失敗は行動を消費しない。
- 技は原資料の `lv` 以上で使用できるように接続した。`needMp()` の本体が未受領のため、不足時はMPも行動も消費しない検証を補った。
- 敵が全滅すれば勝利、味方が全滅すれば敗北。勝利後だけ次の階層へ進める。最終階層・エンディングは決めていない。
- 装備交換は所持・職業・重複装備を検証し、旧装備の能力値を引いて新装備を加える。現在のHP・MPは新しい上限までに収める。素材不足の製作は所持品・素材を変更しない。

### 敵の実行

行動予告の選択は元の条件を使用し、未受領の実行式を下記で補った。ダメージの最終計算は移植した `hit()` を使う。

| 行動 | 仮処理 |
| --- | --- |
| 通常攻撃 | 攻撃力に乱数−2〜4を加えて攻撃 |
| 再生・仲間回復 | 自分の最大HPの20%、生存中の敵全員の最大HPの12%を回復 |
| 反射 | 反射フラグを立てる。反射時の35%ダメージは元の `damage()` の式 |
| 石の守り・敵全体の守り | 元の守備効果を確認できないため、ログを出して通常攻撃に置き換える |
| 遠吠え・怒り | 攻撃力を1.2倍にして状態フラグを立てる |
| ボスの溜め・溜め大技 | 溜め状態にし、次の実行時に攻撃力1.6倍で単体攻撃 |
| 弱った味方狙い・渾身の一撃 | HP割合が最も低い味方へ1.2倍、単体へ1.3倍 |
| 2回攻撃 | 同じ対象が生存している間、0.65倍で2回攻撃 |
| 火種・ブレス・罠・波動・呪い等の全体行動 | 生存中の味方全員へ0.7倍。個々の追加効果は再現していない |
| MP吸収 | MPを3減らし、0.6倍の攻撃 |
| 毒 | 0.8倍の攻撃と3回分の毒。毒耐性の定義を適用し、敵行動終了後にHPを直接3減らす |
| 生命吸収 | 単体へ攻撃し、自分を攻撃力の30%回復 |
| 行動不能 | 実行を1回飛ばし、残数を減らす |

### 道具・報酬・開発用補給

- 薬草はHP25、上薬草はHP60、魔力水はMP14、万能薬は毒解除、復活石は倒れた味方を最大HPの50%で復活。使用時に所持数と対象の生存状態を確認する。
- 勝利EXPは各 `30 + 階層×10`。初期の必要EXP35は原資料を使い、それ以降は1.4倍を切り上げる。レベルごとに最大HP+6、最大MP+3、攻撃+2、防御+1、SP+2。
- 生存者は戦後HP20%、MP20%＋`manaAfterBattle`分を回復。素材は各 `max(1, round(難易度報酬倍率×(1+階層/5)))` を加える。ドロップ抽選やクエスト報酬ではない。
- 「開発用補給（仮）」は全快・毒解除、Lv8以上、SP+15、各素材+20、薬草・魔力水・復活石を各+5、基本装備全31種の未所持分を追加する。レベル数値を上げるだけで通常の成長能力値は追加しない。敗北状態からも再開できる。
- セーブを作っていないため、ゲーム選択に戻る・最初から始める・終了する操作で状態は失われる。

### 移植時に変更した点

- DOM・CSSをGodotの画面とポップアップへ置き換えた。3列のパーティ・敵・ログ、2列のコマンド／一覧、HP・MP・LIMIT、予告と対象選択を残した。
- 固定1280×720の既存プロジェクトに合わせて配置し、長い一覧はスクロールにした。HTMLのスマートフォン用1列レイアウトは移植していない。
- 絵文字の敵画像は環境によって欠けるため、Godotで描く簡単な図形に置き換えた。原資料の絵文字はデータに残した。
- HP変化の浮き文字を追加した。元のCSS演出の警告バナー、揺れ、フラッシュ、勝利演出はすべて同じにはしていない。
- 製作装備のIDは日時と乱数の組み合わせから、1プレイ内の連番へ変更した。所持・重複・セット判定には基底IDも使う。
- `skillMode` は技の効果処理後に解除する。原資料は末尾が未受領なので、その版の解除処理の有無は未確認。
- `project.godot` の起動先をゲーム選択に変更。既存のステージ選択に戻るボタンとEsc／Backを追加した。プレイヤー、チュートリアル、ステージ2、HUD、アクションのギミックコードは変更していない。
