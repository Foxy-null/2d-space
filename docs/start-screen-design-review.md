# 提供ロゴへの差し替え：3回のデザイン確認

確認モードはfull。対象はGodot 4.7.2のスタート画面、ロゴの周囲、忍者の登場、STARTのフォーカス・ホバー・決定、ステージ選択への遷移。既存のTheme、TextureRect、Tween、CanvasItem描画で調整した。添付ロゴは元ファイルとバイト単位で一致し、画素・透明度・文字は変更していない。

## 1回目：ロゴの配置と読みやすさ

[1回目の画面](screenshots/title-review/round-1.png)で、縦長の画像を歪めずに表示できることを確認した。新しいロゴに合わせて表示枠を700×440へ変更し、粒の配置も画像の実際の表示寸法から求めた。

忍者の着地点は以前のSTARTの高さのままで、ボタンより高く浮いて見えた。着地点を45px下げた。また、フォーカス枠を水色から金色へ変更し、操作説明をクリーム色と暗い縁取りで読みやすくした。

## 2回目：登場とワープの動き

[2回目の画面](screenshots/title-review/round-2.png)と動画を確認した。[下降中](screenshots/title-review/round-2-descent.png)に忍者がロゴの下端へ近づく箇所があり、曲線の後半を下げて余白を確保した。

ワープの中心も画面中央からロゴの中央へ移し、ロゴから光が広がるようにした。光の色は水色から暖かい白金色へ揃えた。粒は金色の手裏剣型を8個とし、約3.6秒の周期で明滅する。赤い円と筆文字を主役にして、周囲の粒が目立ちすぎない量に抑えた。

## 3回目：画面サイズと操作時の最終確認

[1280×720](screenshots/title-review/round-3.png)と[960×540](screenshots/title-review/round-3-small.png)で、ロゴ・忍者・START・操作説明の位置を確認した。[下降経路](screenshots/title-review/round-3-descent.png)、[ホバー](screenshots/title-review/round-3-hover.png)、[決定直後](screenshots/title-review/round-3-launch.png)も確認した。

登場部分は動画を0.1倍相当のフレーム列にし、忍者と文字の間隔、明滅・拡大の連続性を確認した。最終確認では、はみ出し、文字の隠れ、操作の妨げになる動きは見つからなかった。

## 採用しなかった案

| 候補 | 理由 |
| --- | --- |
| 赤い粒を多く流す | ロゴの赤い円と競合するため、粒は金色を中心にした |
| 背景やステージ選択全体を暖色へ変更する | 提供ロゴと周囲の調整で統一でき、既存の宇宙基地の背景と選択画面の配色を保てる |
