# ステージ3：壁キックと重力

状態：9室を実装済み。第1室は交互の張り出し、第2室は反転中の下側への壁渡りで、壁キックを使う地形へ調整した。1・2部屋目にSpringと反発板を加え、3〜6部屋目の後半にも穴と異なるギミックを配置した。経路の矢印と説明文は初期状態で非表示。

## 現状と既存の方針

- ステージ1は、16部屋のチュートリアル本編と任意のSuperdash練習部屋で構成される。
- ステージ3は選択画面に「壁キックと重力」と表示され、1部屋目から開始できる。
- 実装済みステージは自由に選択できる。前のステージのクリアを開始条件にしない。
- 選択画面へ戻ると部屋の進捗を破棄する。確定した巻物は保存する。
- 既存のギミックには重力ゲート、ダッシュ、壁アクション、クリスタル、Spring、PinballSpring、風ゾーン、持てる物体、重量スイッチがある。

出典：[ステージ選択の仕様](stage-selection.md)、[README](../README.md)、[用語集](../CONTEXT.md)。

## 決定した方向性

第３ステージでは、壁キックと重力反転のギミックを前面に押し出す。

壁キックは、壁を掴んで上がる「壁登り」と区別する。壁から反対側へ跳び出す動作を課題の中心に据える。

星のぼりの塔に続く本編ステージとして、既存6室に応用3室を加えた9部屋で構成する。第1・7・8室は寄り道や上層に合わせて部屋内を縦へスクロールする。難易度アップの要望を受け、チュートリアルで覚えた操作を連続して使う中級向けの配置に調整した。後半ほど連携とタイミングの課題を増やす。

主課題は「壁キックでゲートを通過し、反転後に別の壁を蹴って次の足場へ渡る」とする。ダッシュと壁登りは補助として使えるままにし、張り出しやゲートを含む地形で壁キックと反転を使う経路を作る。

重力ゲートは静止するものを中心に配置し、終盤に移動ゲートを使う課題を入れる。

## 既存の動作による制約

- 同じ壁を蹴って戻る動作を繰り返しても、蹴り出した高さより低い位置へ戻る。壁キックで登る配置には向かい合う壁を使い、幅と高さは実際の入力で攻略して検証する。
- 壁キックは、通常重力では画面上へ、反転中は画面下へ跳び出す。横の速度は720px/s、重力に逆らう速度は560px/s。
- ダッシュ中以外に重力ゲートを通過すると、縦の速度が0になる。横の速度は残る。空中での連携は、この挙動を前提に配置する。
- ダッシュは既存の設定で無効化できる。壁キックを残して壁Grab・壁登りだけを無効化する専用設定はない。
- 壁登りを残しながら、張り出しで壁キックを使わせる配置はチュートリアルの2部屋目にある。
- 既存の到着台は、通常重力で上面に着地すると押せる。操作課題を設けずに解錠することもできる。
- 既存の部屋切り替えと復帰処理では、重力Down、速度0、ダッシュ回復、壁スタミナ最大に戻す。

出典：[プレイヤー](../scripts/player.gd)、[壁キックの回帰テスト](../tests/wall_jump_regression_test.gd)、[チュートリアル](../scenes/tutorial.tscn)、[到着台](../scripts/arrival_switch.gd)、[部屋切り替え](../scripts/tutorial.gd)。

### 第1室の壁キック区間

修正前は、右入力とGrab・上入力だけで右壁の上へ登り、そこから歩いてUp・Downゲートと天井のSpringを通ると、壁キック0回・Dash0回・復帰0回で到着できた。重力反転を通ることと、壁キックを使うことは別の課題だった。

右壁を上端Y=120pxまで伸ばし、X=584〜644pxに2つの張り出し（Y=426〜454px、196〜224px）を置いた。左壁の下端はY=490pxとし、既存の張り出しはY=320〜348pxに残す。3つの張り出しの上面には短いトゲを置く。壁登りは張り出しの下で止まり、ダッシュで一段を越えても、その上で着地してダッシュを戻すことはできない。トゲは既存のSpikeBlockを静止させ、Stage3の現在室にだけ反応する設定で使う。共通Player・Dash・SpikeBlockの処理は変更しない。使用回数を記録して出口を閉じる仕組みも追加しない。Upゲートは40px右のX=900pxへ移し、最後の壁上に一度着地してから歩いても、反転後に天井Springへ届くようにする。

Springから左右の壁を4回蹴り替える攻略例はダッシュなしで成立する。各回の数自体はクリア条件ではない。下には連続した安全な床があり、最初の壁掴みを放しても戻って試せる。張り出しの下面と壁の側面は掴めるままにし、天面の危険だけを形で見せる。説明は増やさず、任意ヒントの既存の文と矢印を新しい経路へ更新する。

### 第2室の天井と下側の壁渡り

修正前は、入口で通常Jump・上Dashを使ってUpゲートの上を避け、左壁の外側を登ってから中央へ降りると、床を歩くだけで到着台へ進めた。実入口から重力反転0回・壁キック0回・Dash1回・復帰0回で再現した。反転する経路でも、天井の穴を跳んだあとに左へ移動して下Dashを使い、KickLanding下面で補充し、反発板と出口壁からDownゲートへ歩いて入れば、壁キック0回・Dash1回・復帰0回で到着できた。

入口UpゲートはX=180pxのまま、既存の天井下面Y=80pxと床上面Y=640pxの間へ収めた。上下を回るには地形を抜ける必要がある。天井の穴は幅100pxを保ってX=460〜560pxへ寄せ、右壁もX=600pxへ近づけた。反転中に左の段差の下へ蹴り、壁を降りてから右壁の先端Y=510pxの下へ蹴り戻る。段差の下面と壁の先端には短い既存トゲを配置し、登り切って補充する迂回を防ぐ。下側に動けるよう中央の床X=400〜900pxを切った。到着後は既存のReturnBridge処理で穴を埋める。

KickLandingは全幅240pxとし、壁を渡った先の右側下面で静止してDashとスタミナを戻せる。独立レビューでは、左へ張り出した下面でDashを補充し、Jumpと下Dashで天井へ戻る壁キック0回の経路も再現した。その左下面だけに短い既存トゲを置き、正規経路の右側休憩面は残した。左の張り出しは維持し、右壁を深く降りてから下Dashで先端を回る経路も防ぐ。天井の反発板・出口壁・Downゲートは残した。常設ラベル、能力制限、使用履歴による出口ロックは追加していない。第1室の配置や共有Player・Spring・GravityGateも変更していない。

### 第3室の空中ジャンプ

旧配置では、実入口から壁キックでUpゲートへ入り、前半の穴を通常ジャンプで渡った後、後半のX=666pxからジャンプして16フレーム後に右ダッシュすると、追加ジャンプ0回・死亡0で到着できた。クリスタルは拾っていたが、その権利を使わなくても進めた。天井の穴を450pxへ広げる案でも右下ダッシュによる代用が残ったため、横の距離だけの課題は採用しない。

現在は幅330pxの中間天井で安全に止まり、真下の靴から追加ジャンプと下ダッシュをつなぐ。吊り壁はX=840〜860px、Y=-80〜470pxで、左側に既存の静止SpikeBlockを置く。壁を掴んで深さを稼ぐ代用はできず、画面上からも回れない。Downゲートは（940, 500）、出口床はX=940〜1280px・上面Y=640pxとし、反転後の弱い横入力でも着地できる幅を残した。

通常重力の壁上から深く落ち、60フレーム後に斜め上ダッシュすると出口へ届く試行も見つかった。床を薄い片面足場にしても通ったため、その案は採用しない。床の穴の底Y=680pxに見えるトゲを置き、深い落下からの代用を防ぐ。クリア後の橋はトゲより手前へ描画する。橋の上のPlayerは危険範囲に入らず、左へ戻れる。

独立レビューでは、通常重力の壁上から上DashとGrabで中間天井の屋根へ登り、補充してから左へ落ちて右へ戻る経路も成立した。谷底直前から右上Dashすると、クリスタル取得・空中ジャンプ・重力反転なしで、死亡0のまま実到着台まで進めた。入口と中間天井は下面Y=80pxを保ち、上面だけY=-160pxまで高くして、この屋根の補充を防ぐ。反転中の休憩面と天井の穴は変えない。吊り壁のトゲも下端Y=470pxを保って歯の描画刻みを合わせ、見える歯だけが判定より下へ延びないようにした。
