# 自由制作ステージ

作者が自由に作るための補助枠。本編のステージ1〜5とは別に、選択画面の「自由制作ステージ（補助枠）」から入る。キャラクター、背景、地形、ボタン、到着台は既存のデザインを引き継ぐ。

初期状態は1280×720の1画面。平らな床、左右の境界、開始地点、右側の到着台だけを置く。壁アクションとダッシュは最初から使える。到着台にジャンプして乗るとクリアを表示し、そのまま練習できる。

![自由制作ステージの初期画面](screenshots/free-stage.png)

## 編集する場所

Godotで `scenes/free_stage.tscn` を開き、配置を編集する。F6でこのステージだけを実行できる。F5では選択画面から開始する。

| ノード | 編集する内容 |
| --- | --- |
| `Terrain` | 床や足場、壁。`Floor` の当たり判定と `Visual` の輪郭を揃えて編集する |
| `Objects` | 既存のばね、風、重力ゲート、クリスタル、運搬物などのシーンを追加する |
| `Spawn` | 開始・やり直しで戻る地点。プレイヤーが床や壁にめり込まない場所に置く |
| `Goal` | 到着台。原点を床の表面に合わせる |
| `Camera2D` | 固定カメラ。初期状態では画面中央を表示する |

背景を変える場合はルートの `metadata/environment_theme` を0〜4に変更する。0は宇宙基地、1は生活圏、2は未開発、3は溶岩、4は邪悪なオーラ。背景と地形の絵柄は既存の仕組みで揃う。

R / Start、または右上の「やり直す」で `Spawn` に戻る。重力、ダッシュ、スタミナ、運搬物と、`Objects` に置いたクリスタル・移動ゲートをリセットする。画面の上下へ大きく外れた場合も開始地点に戻る。クリア表示はそのプレイ中だけ保ち、選択画面から入り直すと初期化する。Esc / Back・Select、または右上のボタンで選択画面へ戻れる。

## 確認

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script res://tests/free_stage_test.gd
```

成功時は `FREE_STAGE_TEST_OK` と終了コード0。初期の配置を実入力だけでクリアし、やり直し・ギミックのリセット・再入場を確認する。コースを編集した後は、テストの攻略入力も配置に合わせて調整する。
