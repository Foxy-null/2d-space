# ステージ6・追撃と防御の再調整

作業先：`feat/hikariyamaseistage6overhaul`。mainへの反映なし。

## 実装した変更

- 距離と観測した移動速度で技を選択。遠距離の灰雲、6発同時追尾、10本の山なり長針、18発の追従連射を追加・強化。
- 地形への着弾角度を保持。飛行中の針は持った箱・置いた箱へ刺さり、箱と一緒に動く。地形の針へ箱を投げると先端を覆う固定足場になる。
- 傘は地上でも開き、頭上からの弾を防ぐ。屋根の上で雨が止まる。ダッシュ中は閉じる。
- 灰は8秒、連射の短針は5秒で崩れる。固定足場は残す。0.2秒の被弾停止に対して0.75秒の連続被弾・捕獲猶予、復帰直後は0.8秒の猶予を設定。
- 箱の固定位置が忍者に重なると固定しない。箱の軌道では、敵より奥にある針へ先に固定される誤判定も修正。
- 登場時に総称と個体名を表示。その後は画面外も含む技・探索・巡回を表示し、個体名の常時表示を廃止。
- 出口台を踏むと隔壁が開き、追加通路を歩いて次室へ進む。次室では入口壁を破る演出を挟む。境界で部屋を読み替える構造は維持。
- 12室へ各1,000pxの上下通路、最終室へ1,120pxを追加。13室の横幅の合計は33,400pxから46,520pxへ約39%増加。横幅の合計は探索の密度やプレイ時間の指標ではない。
- 環境プレビューの下へ17項目の「キャラクターと道具の図鑑」を追加。

## 不具合の原因と対策

| 問題 | 原因 | 修正 |
| --- | --- | --- |
| 刺さった針が全部同じ向きになる | 地形の法線へ向きを置き換えていた | 衝突直前の進行方向を保持 |
| 箱へ針が刺さらない | 物体への接触を消滅として処理。保持物は物理レイヤーも無効 | 箱への追従と保持物の交差判定を追加 |
| 灰の後に動けなくなる | 復帰点の残留針、連続被弾、忍者と重なる箱の固定が重なり得た | 復帰猶予、被弾猶予、灰の寿命、固定位置の検証 |
| 屋根が灰雲に対して役に立たない | 屋根を見つけると、その下へ雲を置いていた | 雲を屋根の上へ生成 |
| 投げた箱が敵に届かない | 同じフレームで敵より奥の針へ先に固定できた | 軌道上の接触順で処理 |
| 敵が出口台を作動させる | 忍者と敵の共通クラスだけで判定 | 自操作キャラのグループも確認 |
| 拡張後、出口付近の配置が変わる | 部屋幅を増やした後に既存の壊れる足場を幅の割合で生成 | 元の配置を生成してから拡張 |

## 次に優先したい改善

1. **再発見へつながる合流点。** 見失わせた後、敵が何千pxも後ろへ残る部屋がある。瞬間移動で追い付かせず、上道と下道が短い間隔で合流し、敵が視認して追跡へ戻れる配置を試す。完全な経路探索は今回追加していない。
2. **針で作る近道の価値を上げる。** 通常路でも進めるが、受け壁へ長針を誘い、箱を刺せば高い回復地点や安全なショートカットへ届く配置を増やす。成功で敵との差が広がることが個性になる。
3. **部屋ごとに判断を一つに絞る。** 空中連携、逆重力、物運び、18連射を同時に要求し続けると読みにくい。第2室は長針と扇形で箱の使い分けを学び、狭い第11室では連射を外した。第9・12室は初見試遊の失敗地点を見て、遮蔽物か安全な待機場所を追加する候補。
4. **封鎖と反撃の動線を再試遊する。** 封鎖は通電を維持し、2秒の怯み中に制御盤へ移る。条件は達成できるが、移動と照準の習熟が必要。まず制御盤までのルートが読み取れるかを人の試遊で確かめ、敵を一律に弱くする前に導線を調整する。
5. **数値の合格基準を人の試遊で決める。** 初見の人に「何で失敗したか」「次は何を試すか」を説明してもらう。攻撃名が読めるか、傘が閉じる瞬間が分かるか、箱が固定されたことが見えるかを優先する。自動入力のタイムを目標時間にはしない。

既存の移動・環境・運搬、ステージ1〜5、選択・ポーズ・クリア・表示を含む21本の回帰テストと、追加の追撃・防御・復帰76項目を確認。通常入力の攻略は敵の停止、瞬間移動、能力補充、時間・鍵・命中数の書き換えを使わない。録画の具体的な試行回数と所要時間は添付の評価資料を参照。
