# ステージ選択

## 確定した仕様

スタート画面のSTARTから、5つのステージを左から右へ並べた選択画面に進む。起動時のロゴと操作は [スタート画面](start-screen.md) を参照。

| ステージ | 表示 | 開始地点 |
| --- | --- | --- |
| 1 | チュートリアル | 1部屋目。16部屋の本編と任意の17部屋目を含む |
| 2 | 星のぼりの塔 | ふもと。全6区間の上昇コース |
| 3 | 壁キックと重力 | 1部屋目。全6部屋 |
| 4 | 星渡りの回廊 | 1部屋目。全6部屋 |
| 5 | 暴風バンパー峡谷 | 1部屋目。全12部屋 |

`sota_sodex_1st`の星のぼりの塔をステージ2として取り込み、以前のステージ2「壁キックと重力」をステージ3へ移した。同じブランチのステージ4も取り込む。詳細は [第2ステージ](stage-2.md)、[第3ステージ](stage-3.md)、[第4ステージ](stage-4.md) を参照。

番号は表示順を表す。ステージ1〜5は自由に選べ、前のステージのクリアを開始条件にしない。開始時はステージ1にフォーカスを置く。右操作でステージ5まで移動でき、右端ではそれ以上進まない。下操作で環境プレビューへ移れる。

背景は宇宙基地。選択中の枠を水色で示す。

![ステージ選択画面](screenshots/stage-selection.png)

## 環境プレビュー

「5つの環境を見る」から、宇宙基地・生活圏・未開発・溶岩・邪悪なオーラの背景・地形・ギミックを操作できるプレビューへ入る。攻略コースとは区別する。数字キー1〜5、ゲームパッドのL／R、選択欄で環境を切り替える。背景の動きはMキー、Y／△、チェックボタンで停止・再開できる。

## 操作と再開

| 操作 | マウス | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| ステージを選ぶ | ステージをクリック | 方向キー＋Enter | 十字キー／左スティック＋A／× |
| スタート画面へ戻る | タイトルに戻る | 選択画面でEsc | 選択画面でBack／Select |
| ポーズを開閉 | ポーズボタン | Esc | Back／Select |
| 現在の復帰地点からやり直す | ポーズ内のやり直し | R | Start |

選択画面はGodot標準のUI入力を使う。全プレイ画面に共通のポーズメニューを用意し、ダッシュのB／○、やり直しのStartとは開閉操作を分ける。部屋の切り替え中にもポーズでき、カメラを含むゲーム全体が止まる。ポーズ内の「ステージ選択に戻る」で帰還確認を表示し、キャンセルでは進み具合を保持する。H・Y／△でメニューは開かない。詳細は [ポーズメニュー](pause-menu.md) を参照。

選択画面へ戻ると進捗を破棄し、再選択するとそのステージの最初から始まる。セーブや途中再開は追加しない。ステージ2〜5の壁アクションとダッシュは最初から使える。

チュートリアルは16部屋目で本編の完了を表示し、17部屋目の任意練習へ進める。塔は頂上の到着台、ステージ3・4は6部屋目、ステージ5は12部屋目の到着台でクリア。クリアしても自動で別のステージへ進まない。

クリア時は全5ステージ共通で「ステージクリア！」と「ステージ選択に戻る [Enter]」ボタンを表示する。Enter・テンキーEnter・マウスクリック・ゲームパッドAで確認なしに選択画面へ戻れる。ポーズ・帰還確認中はクリア表示が入力を受け取らない。クリア前のEnterでは戻らず、Spaceはジャンプとして使える。

## ファイルと確認

- `scenes/stage_select.tscn` / `scripts/stage_select.gd`：選択画面、開始先、フォーカス移動、環境プレビューの入口。
- `scenes/stage_2.tscn` / `scripts/stage_2.gd`：星のぼりの塔。
- `scenes/stage_3.tscn` / `scripts/stage_3.gd`：壁キックと重力。
- `scenes/stage_4.tscn` / `scripts/stage_4.gd`：星渡りの回廊。
- `scenes/stage_5.tscn` / `scripts/stage_5.gd`：暴風バンパー峡谷。「未開発の惑星」を背景に、番号順のバンパー反射と風を使う12部屋。次のバンパーを金色のひし形で囲み、反射済みの番号はチェック印に変わる。すべて反射するとひし形が出口へ移る。これはヒント非表示でも残り、やり直すと番号と最初の目標に戻る。反射をすべてつなぐと部屋の出口が開く。第1〜11室は出口の足場への着地、または画面右端を越えた時点で次の部屋へ進む。落下や赤い障害物への接触で現在の部屋の入口へ戻る。
- `tests/stage_select_test.gd`：起動、表示順、3種類の入力、全5ステージの選択、戻る操作、再入場時の初期化。
- `tests/stage_5_test.gd`：全12部屋の実入力攻略、最終到着台、復帰、ヒント、メニュー、再入場時の初期化。
- `tests/stage_5_exit_test.gd`：第1〜11室の出口着地・空中ダッシュ退出で1回だけ次室へ進むことと、未達成時の退出禁止。

- `scenes/pause_menu.tscn` / `scripts/pause_menu.gd`：全プレイ画面共通のポーズと帰還確認。
- `tests/pause_menu_test.gd`：全体停止・再開、操作、ヒント、やり直し、帰還確認。
- `scripts/stage_clear.gd`：共通クリア表示と選択画面へ戻るボタン。
- `tests/stage_clear_test.gd`：全5ステージのクリア表示、Enter・テンキーEnter・クリックでの復帰。

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script res://tests/stage_select_test.gd
```

`STAGE_SELECT_TEST_OK` と終了コード0を成功条件とする。環境プレビューは `tests/environment_art_test.gd`、各攻略コースは対応するステージテストで確認する。

共通クリア画面は `tests/stage_clear_test.gd`、共通ポーズは `tests/pause_menu_test.gd` で確認する。ステージ5の全12部屋は `tests/stage_5_test.gd`、各部屋を1回の攻略で退出できることは `tests/stage_5_exit_test.gd` で検証する。
