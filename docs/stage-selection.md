# ステージ選択

## 確定した仕様

スタート画面のSTARTから、4つのステージを左から右へ並べた選択画面に進む。起動時のロゴと操作は [スタート画面](start-screen.md) を参照。

| ステージ | 表示 | 開始地点 |
| --- | --- | --- |
| 1 | チュートリアル | 1部屋目。16部屋の本編と任意の17部屋目を含む |
| 2 | 星のぼりの塔 | ふもと。全6区間の上昇コース |
| 3 | 壁キックと重力 | 1部屋目。全6部屋 |
| 4 | 星渡りの回廊 | 1部屋目。全6部屋 |

`sota_sodex_1st`の星のぼりの塔をステージ2として取り込み、以前のステージ2「壁キックと重力」をステージ3へ移した。同じブランチのステージ4も取り込む。詳細は [第2ステージ](stage-2.md)、[第3ステージ](stage-3.md)、[第4ステージ](stage-4.md) を参照。

番号は表示順を表す。ステージ1〜4は自由に選べ、前のステージのクリアを開始条件にしない。開始時はステージ1にフォーカスを置く。

背景は宇宙基地。選択中の枠を水色で示す。

![ステージ選択画面](screenshots/stage-selection.png)

## 環境プレビュー

「5つの環境を見る」から、宇宙基地・生活圏・未開発・溶岩・邪悪なオーラの背景・地形・ギミックを操作できるプレビューへ入る。攻略コースとは区別する。数字キー1〜5、ゲームパッドのL／R、選択欄で環境を切り替える。背景の動きはMキー、Y／△、チェックボタンで停止・再開できる。

## 操作と再開

| 操作 | マウス | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| ステージを選ぶ | ステージをクリック | 方向キー＋Enter | 十字キー／左スティック＋A／× |
| スタート画面へ戻る | タイトルに戻る | 選択画面でEsc | 選択画面でBack／Select |
| ポーズを開閉 | ポーズボタン | Esc | Back／Select |
| 現在の復帰地点からやり直す | ポーズ内のやり直し | R | Start |

選択画面はGodot標準のUI入力を使う。全プレイ画面に共通のポーズメニューを用意し、ダッシュのB／○、やり直しのStartとは開閉操作を分ける。部屋の切り替え中にもポーズでき、カメラを含むゲーム全体が止まる。ポーズ内の「ステージ選択に戻る」で帰還確認を表示し、キャンセルでは進み具合を保持する。H・Y／△でメニューは開かない。詳細は [ポーズメニュー](pause-menu.md) を参照。

選択画面へ戻ると進捗を破棄し、再選択するとそのステージの最初から始まる。セーブや途中再開は追加しない。ステージ2〜4の壁アクションとダッシュは最初から使える。

チュートリアルは16部屋目で本編の完了を表示し、17部屋目の任意練習へ進める。塔は頂上の到着台、他の本編は6部屋目の到着台でクリア。クリアしても自動で別のステージへ進まない。

クリア時は全4ステージ共通で「ステージクリア！」と「ステージ選択に戻る [Enter]」ボタンを表示する。Enter・テンキーEnter・マウスクリック・ゲームパッドAで確認なしに選択画面へ戻れる。ポーズ・帰還確認中はクリア表示が入力を受け取らない。クリア前のEnterでは戻らず、Spaceはジャンプとして使える。

## ファイルと確認

- `scenes/stage_select.tscn` / `scripts/stage_select.gd`：選択画面、開始先、フォーカス移動、環境プレビューの入口。
- `scenes/stage_2.tscn` / `scripts/stage_2.gd`：星のぼりの塔。
- `scenes/stage_3.tscn` / `scripts/stage_3.gd`：壁キックと重力。
- `scenes/stage_4.tscn` / `scripts/stage_4.gd`：星渡りの回廊。
- `scenes/pause_menu.tscn` / `scripts/pause_menu.gd`：全プレイ画面共通のポーズと帰還確認。
- `tests/pause_menu_test.gd`：全体停止・再開、操作、ヒント、やり直し、帰還確認。
- `scripts/stage_clear.gd`：共通クリア表示と選択画面へ戻るボタン。
- `tests/stage_clear_test.gd`：全4ステージのクリア表示、Enter・テンキーEnter・クリックでの復帰。
- `tests/stage_select_test.gd`：スタート画面からの起動と往復、表示順、3種類の入力、準備中の項目、戻る操作、再入場時の初期化。

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script res://tests/stage_select_test.gd
```

`STAGE_SELECT_TEST_OK` と終了コード0を成功条件とする。環境プレビューは `tests/environment_art_test.gd`、各攻略コースは対応するステージテストで確認する。

共通クリア画面は `tests/stage_clear_test.gd` で全4ステージの表示と確認なしの帰還を検証し、33項目が成功した。ステージ選択ではスタート画面との往復とポーズ経由の帰還を含む100項目が成功した。共通ポーズは142項目。攻略・復帰と到着台を含む計10本のヘッドレステストが成功した。共通ポーズは描画ありでも142項目が成功した。
