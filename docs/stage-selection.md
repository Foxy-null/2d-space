# ステージ選択

## 確定した仕様

スタート画面のSTARTから、5つのステージを左から右へ並べた選択画面に進む。起動時のロゴと操作は [スタート画面](start-screen.md) を参照。

| ステージ | 表示 | 開始地点 |
| --- | --- | --- |
| 1 | チュートリアル | 1部屋目。16部屋の本編と任意の17部屋目を含む |
| 2 | 星のぼりの塔 | ふもと。全19区間の上昇コース |
| 3 | 壁キックと重力 | 1部屋目。全25部屋 |
| 4 | 星渡りの回廊 | 1部屋目。全24部屋 |
| 5 | 暴風バンパー峡谷 | 1部屋目。全27部屋 |

`sota_sodex_1st`の星のぼりの塔をステージ2として取り込み、以前のステージ2「壁キックと重力」をステージ3へ移した。同じブランチのステージ4も取り込む。詳細は [第2ステージ](stage-2.md)、[第3ステージ](stage-3.md)、[第4ステージ](stage-4.md) を参照。

番号は表示順を表す。ステージ1〜5は自由に選べ、前のステージのクリアを開始条件にしない。開始時はステージ1にフォーカスを置く。右操作でステージ5まで移動でき、右端ではそれ以上進まない。下操作で環境プレビューへ移れる。

背景は宇宙基地。カードには番号・静止した小さな絵・ステージ名を縦に並べ、練習、塔の上昇、壁と重力、相棒、バンパーと風を表す。説明段落と「プレイする」の繰り返しを省き、自由に選べる旨と操作を短い行で表示する。選択中は水色の枠を付ける。カード全体が標準のButtonで、絵や文字はマウスとフォーカスの操作を妨げない。ボタンのアクセシビリティ名には番号とステージ名を残す。

## 環境プレビュー

「背景・ギミックを見る」から、宇宙基地・生活圏・未開発・溶岩・邪悪なオーラの背景・地形・ギミックを操作できるプレビューへ入る。攻略コースとは区別する。数字キー1〜5、ゲームパッドのL／R、選択欄で環境を切り替える。背景の動きはMキー、Y／△、チェックボタンで停止・再開できる。

## 操作と再開

| 操作 | マウス | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| ステージを選ぶ | ステージをクリック | 方向キー＋Enter | 十字キー／左スティック＋A／× |
| スタート画面へ戻る | タイトルに戻る | 選択画面でEsc | 選択画面でBack／Select |
| ポーズを開閉 | ポーズボタン | Esc | Back／Select |
| 現在の復帰地点からやり直す | ポーズ内のやり直し | R | Start |

選択画面はGodot標準のUI入力を使う。全プレイ画面に共通のポーズメニューを用意し、ダッシュのB／○、やり直しのStartとは開閉操作を分ける。部屋の切り替え中にもポーズでき、カメラを含むゲーム全体が止まる。ポーズ内の「ステージ選択に戻る」で帰還確認を表示し、キャンセルでは進み具合を保持する。H・Y／△でメニューは開かない。詳細は [ポーズメニュー](pause-menu.md) を参照。

選択画面へ戻ると進捗を破棄し、再選択するとそのステージの最初から始まる。途中進捗の保存や途中再開は追加しない。確定した巻物の収集記録は保存する。ステージ2〜5の壁アクションとダッシュは最初から使える。

チュートリアルは16部屋目で本編の完了を表示し、17部屋目の任意練習へ進める。塔は頂上の到着台、ステージ3は25部屋目、ステージ4は24部屋目、ステージ5は27部屋目の到着台でクリア。クリアしても自動で別のステージへ進まない。

クリア時は全5ステージ共通で画面上部に「ステージクリア！」の小さな通知と「選択へ戻る [Enter / Y・△]」ボタンを表示する。Enter・テンキーEnter・マウスクリック・ゲームパッドY／△で確認なしに選択画面へ戻れる。A／×はジャンプなどの自由練習に使える。ポーズ・帰還確認中はクリア表示が入力を受け取らない。クリア前のEnterでは戻らず、Spaceはジャンプとして使える。

## 巻物の収集記録

ステージカードに巻物の絵と「獲得数 / 実配置総数」を表示する。未クリアでも安全な着地で確定した巻物は保存し、部屋の途中進捗とは分ける。確定前に死亡・やり直し・帰還した巻物は保存しない。収集数でステージやゴールを制限せず、未配置のステージは0 / 0と表示する。

重力ステージの巻物総数は8個。第22・24室の左上への任意枝2本も、従来と同じ保存と読み上げ名付きの個数表示へ加算する。

チュートリアルの巻物総数は8個。第5室の空中Dash補充と第11室の箱の足場から上へ寄る2本も保存し、選択の個数とaccessible名へ反映する。必須16室と任意17室、元の説明と主経路は維持する。
