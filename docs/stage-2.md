# ステージ2：星のぼりの塔

2026-10-31。参考図に沿って、旧34区間を主経路7室・寄り道3室の計10室へ作り直した。[合意した仕様](stage-2-redesign.md)、[Q1〜Q9の回答履歴](stage-2-redesign-decisions.md)を参照。

## コースと復帰

左下のふもとから出発し、バネと壁キック、トゲのある回廊、崩れる青い薄板をつないで、最上部のロケットを目指す。巻物は第2室と寄り道3室に各1本、計4本。巻物なしでも主経路を最後まで進める。

各室内ではカメラがキャラクターを追い、端ではその部屋の外を映さない。部屋の境界で切り替わり、前室と寄り道へ引き返せる。死亡・R・ポーズメニューのやり直しでは、現在の部屋へ最後に入った入口に戻る。再入室や再挑戦では板とクリスタルを復元する。

青い薄板は下から通れず、最初に上へ乗ってから0.5秒後に崩れる。離れてもカウントは続き、崩壊後2秒で復活する。プレイヤーと重なる間は復活を待つ。巻物は薄板では確定せず、崩れない安全な床へ0.2秒着地して確定する。

## 見た目と音楽

地形は灰色の単色。上へ登るほど空が暗くなり、星は位置と大きさを固定した不規則な配置でまばらに散らす。寄り道3室すべてで既存のA静版、主経路ではA通常版を流す。

## クリアと記録

ロケットへ近づくと自動で入口まで歩いて乗り込み、暗転して既存の3層クリア画像を表示する。決定でステージ選択へ戻る。共通ポーズメニューから演出をスキップでき、途中のやり直しや帰還でも操作状態を復元する。

保存形式はバージョン3。旧ステージ2の巻物8本とクリア印を新コースへ引き継がず、他ステージの進捗と操作・画面設定は保つ。新しい巻物4本とクリア印は、以降の再プレイ・再読込でも保持する。[記録移行の判断](adr/0002-stage-2-redesign-starts-new-progress.md)を参照。

## 実装と検証

- `scripts/stage_2.gd`：部屋の構築、移動、復帰、音楽の切り替え、クリア演出。
- `scripts/tower_landscape.gd`：参考図から作成した地形、トゲ、通り口、ギミックと巻物の配置。描画と当たり判定は同じ形から作る。
- `scripts/crumbling_platform.gd`：薄板の接触、予兆、崩壊、復活と重なり待ち。
- `scripts/ascent_backdrop.gd`：実際の高度に応じた空と固定乱数による星。
- `tests/stage_2_test.gd`：全通り口の往復、入口復帰、トゲ・落下、板、巻物、静版、乗り込み・クリア・スキップ。
- `tests/stage_2_route_test.gd`：開始地点からロケットのクリア画面まで実入力で連続攻略。巻物なしの主経路、第2室の巻物、寄り道3室の回収・帰還、バンパーの往復反射。
- `tests/ascent_backdrop_test.gd`：星の固定配置と大きさのばらつき、高度と降下による空の変化、ポーズ。

```sh
python tests/run_checks.py --godot /path/to/godot --smoke --timeout 120 stage_2_test.gd stage_2_route_test.gd ascent_backdrop_test.gd gimmick_retry_contact_test.gd game_progress_test.gd collection_progress_test.gd
```

Godot 4.7.2で全9シーンの起動、機能101項目、連続攻略・回収28項目、背景12項目、やり直し接触33項目、進捗30項目、収集記録のチェックが通過した。OpenGL描画ありでも114項目を確認し、全10室・室内追従の2場面・クリア画面を撮影した。

最新mainとの統合後、共通の開始演出605項目、死亡演出142項目、音声172項目、ポーズ170項目、巻物39項目、ステージ選択272項目まで確認した。巻物の部屋移動テストは、開始演出への待機を修正後、追加実行を省略した。開始・死亡アイリス、改訂BGM、巻物の新しい絵は現行mainの実装を維持し、ステージ2の落下とトゲも共通の死亡演出へ接続した。巻物の共有テストは開始演出の終了を待ってから操作するよう更新した。検証は使い捨ての保存先で行い、実際のプレイデータには書き込まない。旧34区間専用の攻略テスト31本は新しい部屋のテストへ置き換えた。

地形の調整では、回廊の段差に安全な着地点を確保し、最後のバネ先の高い棚を広げた。プレイヤー共通の移動・ジャンプ・ダッシュ性能は変更していない。

実機ゲームパッド、初見プレイヤーによる難度評価、弱いスティック入力と操作時機の余裕は未確認。実入力の攻略検証は固定60fpsで行った。
