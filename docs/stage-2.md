# 第2ステージ

設計中。合意した内容をこの文書に記録し、仕様がまとまってからコースを実装する。

## 確定した方針

- なるべく簡単なステージにする。
- ギミックを使って進む遊びを含める。
- 第1ステージと同じ、1画面の部屋をつなぐ形式にする。
- 初見でのクリア時間は5〜10分を目安にする。
- Jump Crystal、Dash Crystal、重力ゲートを使う。

Jump Crystalは追加空中ジャンプを1回与える。Dash Crystalは消費したダッシュを回復する。重力ゲートは床と天井を切り替えるために使う。

## 検討中の案

以下は提案であり、まだ合意していない。

### 部屋構成

各ギミックを個別に使う課題から始め、最後に簡単な組み合わせを試す6部屋の構成を提案する。

| 部屋 | 遊びの案 | 簡単にするための配置 |
| --- | --- | --- |
| 1 | 移動・通常ジャンプ・ダッシュで慣らす | 低い段差と広い床 |
| 2 | Jump Crystalで追加空中ジャンプを使う | クリスタルを取りやすくし、着地点を広くする |
| 3 | Dash Crystalでダッシュを回復する | 下に受け床を置き、落ちても再挑戦できる |
| 4 | Upゲートで天井へ、Downゲートで床へ戻る | 固定ゲートと広い床・天井 |
| 5 | 反転中にJump Crystalで段差を越える | 天井側でも広い着地点を設ける |
| 6 | 3種類を順番に使ってゴールへ進む | ギミックの間に休める足場を置き、素早い連続入力を要求しない |

部屋数と配置は5〜10分という目標に向けた案であり、実際のクリア時間はプレイで確認する。

### 進行とやり直し

- 基本操作は最初から使える。
- 各部屋は地形を越えて到着台を押すと出口が開く。操作の使用回数を数えるミッションは設けない。
- 落下やR / Startでは、現在の部屋の入口から何度でもやり直せる。
- 復帰時は重力Down、速度0、ダッシュ使用可能、追加空中ジャンプなし、壁スタミナ最大に戻し、その部屋のクリスタルも復帰させる。
- 開いた出口はやり直しても開いたままとし、左へ戻って再挑戦できる。
- 最後の到着台は重力Downで押す位置に置き、第2ステージのクリアを表示する。クリア後も自由に練習できる。
- Esc / Back・Selectと戻るボタンでステージ選択へ戻れる。再選択では最初から開始する。

## 既存の仕組み

第1ステージはチュートリアルで、第2ステージは現在、選択画面の「準備中」枠だけが存在する。既存の選択方針では、実装済みのステージは自由に選べる。

プレイヤーと各ギミックのシーンは再利用できる。チュートリアルの部屋数やミッションは専用の構成になっているため、第2ステージの進行はそのまま流用できるとは限らない。
