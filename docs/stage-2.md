# ステージ2：ほしのさんぽ

気軽に遊べる、簡単な6部屋のステージ。チュートリアルで覚えた操作を最初から使える。

## コース

| 部屋 | 遊びと配置 |
| --- | --- |
| 1：まずはおさんぽ | 広い床と40pxの段差2つ。ジャンプで越える |
| 2：小さな穴をひとっ飛び | 幅140pxの穴。下に受け床があり、落ちてもジャンプで戻れる |
| 3：天井を歩こう | Upゲート、広い天井、Downゲート。左右移動で反転と復帰を体験する |
| 4：クリスタル広場 | 広い床とDash Crystal2個。ジャンプや空中ダッシュを自由に試す |
| 5：ゆっくり動くゲート | 横100pxを45px/sで往復するUpゲート。天井とDownゲートも置く |
| 6：ゴールへおさんぽ | 重力反転、天井側のDash Crystal、最後の到着台 |

精密な壁キックや連続空中ダッシュを必須にしない。Crystalを取ったか、指定操作を使ったかによる進行制限は設けない。敵、トゲ、時間制限、失敗回数の制限はない。

各部屋は1280×720。カメラは部屋内で固定し、部屋移動のときだけ0.28秒で横へスライドする。既存の宇宙背景、足場、ゲート、到着台を使う。

![重力反転の部屋](screenshots/stage-2/room_3.png)

## 進行とクリア

- 到着台は最初から押せる。手前に小さな足場を置き、ジャンプで上に乗れるようにする。
- 重力Downで到着台に乗ると台が沈み、出口の壁が開く。
- 開いた出口から画面右端へ進むと次の部屋へ移る。切り替え中だけ操作を止める。
- 画面左端から前の部屋へ戻れる。クリアした部屋は、そのプレイ中は開いたままになる。
- 6部屋目の到着台でクリアを表示する。自動では別画面へ移動せず、戻って自由に遊べる。

## やり直しと選択画面

落下やR / Startで現在の部屋に入った入口へ戻る。重力Down、速度0、ダッシュ回復、壁スタミナ最大の状態にし、その部屋のCrystalとMoving Gateを初期状態へ戻す。クリア済みの出口は開いたままにする。

Esc / Back・Select、または右上の「ステージ選択へ戻る」で選択画面へ戻れる。部屋切り替え中も使える。再びステージ2を選ぶと進捗を初期化し、1部屋目から開始する。セーブや途中再開は設けない。

選択画面では「ステージ2：ほしのさんぽ」をマウス、キーボード、ゲームパッドで自由に選べる。ステージ1のクリアは必要ない。

## ファイルと動作確認

`scenes/stage_2.tscn`が足場、ギミック、説明文を担当し、`scripts/stage_2.gd`が部屋移動、復帰、クリアを担当する。共通HUDにはステージ用の表示を追加した。到着台は初期状態のロックをInspectorで選べる。

`tests/stage_2_test.gd`は、入口から実入力で6部屋すべての到着台まで進み、自然な部屋移動と最終クリアを確認する。重力UpからDownへの復帰、空中のCrystal取得と再ダッシュ、Rによるやり直し、画面上下への落下、後戻り、3種類の入力による開始と選択画面への復帰、再開始時の進捗初期化も検証する。

成功条件は`STAGE_2_TEST_OK (50 checks)`と終了コード0。選択画面、到着台、既存チュートリアルのテストも実行する。
