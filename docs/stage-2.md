# ステージ2：星のぼりの塔

## コース

上へ登るとカメラが連続して追従する縦コース。全6区間で、1区間の高さ720px、全体の上昇量4320px。小さな足場を24段配置する。画面幅は1280pxのまま、左右へ渡りながら上を目指す。

| 区間 | テーマ |
| --- | --- |
| 1 | 壁を掴んで登り、壁キックで反対の壁や足場へ |
| 2 | バネによる上昇から次の壁へ |
| 3 | 空中の緑のクリスタルでダッシュを回復し、斜め上へ |
| 4 | 紫のクリスタルで追加ジャンプをつなぐ |
| 5 | 生物を保持して追加ジャンプ。壁掴み時には手放す |
| 6 | バネと両クリスタルを組み合わせ、頂上の到着台へ |

通常重力で登る。壁アクションとダッシュは最初から使用可能。着地回数による失敗条件は設けず、小さな足場はダッシュ・壁スタミナの回復や休憩に使える。アイテムを使うと着地を減らして登れ、壁登り中心の経路でも全区間を進める。

## 背景と地形

生活圏の惑星のふもとから、雲の上、星が見える上空へつながる。地表の街や山は序盤にだけ現れ、上昇すると下へ遠ざかる。雲と星には足場より遅い縦方向の視差を付け、空の色を高度に応じて滑らかに変える。

背景はプレイヤーを追うカメラの高さに合わせる。区間の境界では切り替えず、降下や落下からの復帰でも、その高さの景色へ戻る。地表の繰り返しや背景画像の縦引き伸ばしは行わない。足場・左右の壁は生活圏の地形表現に揃える。6か所の復帰足場だけは銀灰色の鉄板にし、明るい縁と鋲・継ぎ目で土の足場と区別する。当たり判定は従来どおり。

左右の壁の外側には、高度によらず透明感のある青空と差し込む日差しを表示する。雲は下端の薄いものを中心に残し、左右それぞれ幅116pxの帯の中で、左上から右下へ45度前後の光の筋を伸ばす。左右で光の向きはそろえ、位置・角度・明るさを10秒周期で動かす。明るい芯と柔らかなにじみを付け、雲も緩やかに動かす。塔の内側の空・地表・雲は壁の外側へはみ出さない。

背景の動作は `scripts/ascent_backdrop.gd`、地表と空の境目は `assets/environments/ascent.gdshader`、検証は `tests/ascent_backdrop_test.gd`。

青空は通常の `scenes/stage_2.tscn` に適用し、ステージ選択からの起動でも表示する。比較用に作った `scenes/stage_2_daylight.tscn` も引き続き開ける。

青空の描画は `scripts/daylight_backdrop.gd`、雲と光の動きは `assets/environments/daylight.gdshader`。背景画像は `assets/environments/daylight-open-sky.png`、生成プロンプトは同じディレクトリの `PROMPTS.md` に記録する。`xvfb-run -a godot --audio-driver Dummy --fixed-fps 15 --path . --script tests/stage_2_daylight_test.gd` でステージ選択から起動し、表示・動き・高度による表示を確認して、`deliverables/` に静止画と動画用フレームを保存する。

## 復帰地点と落下

- 各区間の開始位置に幅240pxの足場があり、番号を表示する。
- 上の区間の復帰足場に着地した時点で更新する。空中で通過するだけでは更新しない。
- 最高到達点から640px落ちるか、最新の復帰足場より180px下へ落ちると自動復帰する。
- R / Startも最新の復帰地点へ戻る。通常重力、速度0、ダッシュ・スタミナ回復、追加ジャンプなしで再開する。
- クリスタルを再出現させ、持てる生物を初期配置へ戻す。カメラも復帰地点へ戻る。
- 選択画面へ戻ると進捗は破棄する。

## 表示・操作

上部に区間名、高度、ダッシュ、追加ジャンプ数、復帰地点、壁スタミナを表示する。

H / Y・△または右上のボタンでお助けメニューを開く。プレイヤー操作を停止し、ヒント切り替え、やり直し、ステージ選択へ戻る操作ができる。メニュー中のEsc / Backはメニューを閉じ、通常時はステージ選択へ戻る。ヒントは初期非表示で、復帰しても設定を保つ。

同じ区間で5回落下すると、右上のお助けメニューボタンの下に「？ おたすけブロック」が現れる。押すと復帰地点に戻り、その区間の登り始めと中盤に幅112pxの足場を1個ずつ追加する。足場は上下左右から衝突する通常のブロックで、下からすり抜けられない。設置後はボタンが「？ ブロックを解除」に変わり、押すとその場で足場を撤去してプレイを続けられる。解放済みの区間では追加のデスなしで何度でも再設置でき、同時に設置する足場は2個まで。落下や手動のやり直しでは残り、次のチェックポイントに到達すると撤去してデス回数もリセットする。初回の出現とR / Start・メニューによる手動のやり直しはデスに数えない。

キーボード・ゲームパッドでは、お助けメニューを開いて↑でおたすけボタンに移動し、決定で設置・解除する。黄色のボタンと足場には丸みのある太字の [M PLUS Rounded 1c ExtraBold](https://github.com/google/fonts/tree/main/ofl/roundedmplus1c) を使い、[フォントのライセンス](../assets/fonts/OFL-RoundedMplus1c.txt)を同梱する。

頂上の到着台を押すとクリアを表示する。自動で画面遷移せず、メニューから戻れる。

## 実装と確認

- `scenes/stage_2.tscn`：Godotエディターで編集できる足場、壁、アイテム、復帰地点、UIの配置。
- `scripts/stage_2.gd`：連続カメラ、復帰更新、落下、メニュー、クリア処理。
- `scripts/player.gd`：既存の復帰範囲を有効・無効にする設定を追加。ステージ2・4では無効にし、ステージ側で落下を判定する。
- `tests/stage_2_test.gd`：実際の物理移動による全24段の登頂、復帰地点更新、クリア、落下復帰、メニュー、再入場を検証。
- `tests/stage_2_assist_test.gd`：区間ごとのデス数、おたすけボタンの解放・設置・解除・再設置、足場の衝突と撤去、やり直し・再入場を検証。
- `tests/stage_select_test.gd`：第2ステージの有効化、方向キー・ゲームパッドでの選択を含めて確認。

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script tests/stage_2_test.gd
```

`STAGE_2_TEST_OK` と終了コード0を成功条件とする。実際に遊んだ際の難易度・テンポはプレイ感に応じて調整する。
