# 第2ステージ：星のさんぽ

なるべく簡単に、ジャンプ・ダッシュ・重力反転を楽しめる6部屋のステージ。初見でのクリア時間は5〜10分を目安とし、実際の所要時間は初見プレイヤーのプレイで調整する。

## コース

第1ステージと同じ、1280×720の1画面の部屋を横につなぐ形式。部屋の中ではカメラが固定され、出口を越えると0.28秒で隣の部屋へスライドする。切り替え中だけ操作を止める。

| 部屋 | 遊び | 配置 |
| --- | --- | --- |
| 1：まずはおさんぽ | 移動・通常ジャンプ・ダッシュ | 低い段差と広い床 |
| 2：紫で二段ジャンプ | Jump Crystalで空中でもう1回跳ぶ | 取りやすい紫のクリスタルと180pxの段差 |
| 3：緑でダッシュ回復 | 空中ダッシュを緑で回復して再ダッシュ | 広い着地点と、下で休める受け床 |
| 4：天井を歩こう | Upゲートで天井へ、Downゲートで床へ | 固定ゲート、広い天井、床側の障害物 |
| 5：天井でも二段ジャンプ | 反転中にJump Crystalで出っ張りを越える | 天井側の紫のクリスタルと広い着地点 |
| 6：星のさんぽのゴール | 紫・緑・重力ゲートを順番に使う | 途中で休める足場と、床側の最後の到着台 |

## 操作とギミック

移動・通常ジャンプ・壁アクション・8方向ダッシュを最初から使える。Jump Crystalは追加空中ジャンプを1回与え、Dash Crystalは消費したダッシュを回復する。赤いUpゲートで天井へ、水色のDownゲートで床へ重力を切り替える。

課題の近くに短い操作説明を置き、HUDには部屋番号、重力、ダッシュの使用可否、追加ジャンプ残数を表示する。制限時間や失敗回数の制限は設けない。

## 到着台と復帰

各部屋の到着台は最初から押せる状態にする。チュートリアルのように特定の操作回数を数えるミッションは設けず、地形を越えて到着台へ着地すると出口が開く。

落下やR / Startでは、現在の部屋に入った入口へ戻る。重力Down、速度0、ダッシュ使用可能、追加空中ジャンプなし、壁スタミナ最大の状態に戻し、その部屋のクリスタルと重力ゲートも復帰させる。押し込み途中の到着台は元の位置へ戻す。復帰直後は物理の位置情報が更新されてからギミックを有効にし、移動前の接触による誤取得や誤クリアを防ぐ。

到着台を押して開いた出口は、やり直しても開いたままにする。左端から前の部屋へ戻れ、反対側から戻った場合は右の入口が復帰地点になる。最後の到着台は重力Downで押す場所に置き、第2ステージのクリアを表示する。その後も前の部屋へ戻って練習できる。

## ステージ選択

ステージ選択画面から、チュートリアルのクリア状況に関係なく開始できる。クリック、方向キー＋Enter、ゲームパッドの十字キー／左スティック＋A／×で選ぶ。

Esc / Back・Select、または画面右上の戻るボタンでステージ選択へ戻れる。部屋の切り替え中も戻れる。再選択では1部屋目から始まり、進捗は保存しない。

## ファイルと動作確認

- `scenes/stage_2.tscn`：6部屋の地形、ギミック、入口、説明文、到着台。
- `scripts/stage_2.gd`：部屋移動、復帰、HUD、出口、クリア表示。
- `scenes/stage_select.tscn` / `scripts/stage_select.gd`：第2ステージの選択と開始。
- `tests/stage_2_test.gd`：実際の入力による全6部屋の攻略、二段ジャンプ、空中ダッシュ回復、重力往復、復帰、逆戻り、クリア、3種類の入力での選択。

Godot 4.7.2で次を実行する。

```sh
godot --headless --fixed-fps 60 --path . --script res://tests/stage_2_test.gd
```

`STAGE_2_TEST_OK`と終了コード0を成功条件とする。押し込み途中のやり直しによる誤クリアと、紫のクリスタル取得直後のやり直しによる誤取得も検証する。
