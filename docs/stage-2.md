# ステージ2：星のぼりの塔

## コース

上へ登るとカメラが連続して追従する全12区間の縦コース。既存の6テーマとCP03の横枝を保ち、後半に6つの応用区間と2つの巻物ルートを加えた。入口の床はy640、頂上はy-10700で、全体の上昇量は11340px。CP01〜07までは720pxずつ、その先は操作の組み合わせに合わせて高低差を変えている。各区間に広い復帰足場を置き、区間の途中にも休憩や次の配置を観察できる足場を設ける。

通常重力で登る。壁アクションとダッシュは最初から使用可能。着地回数による失敗条件は設けず、小さな足場はダッシュ・壁スタミナの回復や休憩に使える。第2区間は入口のバネがないと中間足場へ届かない。区間内の外壁を分断し、通常ジャンプ・8方向ダッシュ・壁登りによる迂回を防ぐ。入口のバネは上向き1450px/s、中間のバネは1100px/s。操作履歴による進行ロックは設けず、地形と既存バネで誘導する。第3区間も外壁を分断し、クリスタルによる回復と複数回のダッシュを必要とする。クリスタルはx740の列に200px間隔で並び、上昇中に次の目標が見える。出口足場は厚さ32pxで、下の側面を長く登る迂回を防ぐ。第4区間の外壁も分断する。最初の休憩足場は幅300px・厚さ16pxとし、通常ジャンプとダッシュでは側面へも届かない440pxの高低差にする。靴は2個とし、次の跳躍から見える位置に置く。右端の休憩足場からCP05へ長く折り返し、2個目の靴もx960へ離す。CP05を片面足場にして下の側面を登れなくし、CP05から前区間の靴を取り戻して相棒の代わりに運ぶ経路を防ぐ。第4区間だけカメラの上方余白を40px広げ、右端の足場をポーズボタンの下に見せる。第5区間は幅360pxの片面足場を使い、壁掴みや相棒を踏み台にする迂回を防ぐ。相棒はCP05中央から右へ離して置き、地上から掴める。途中の着地で相棒の追加ジャンプを回復する。代わりに使えていた靴3個と、この区間の外壁・中継足場を取り除く。第1区間は通常ジャンプとダッシュだけでは届かない430pxの壁を使い、最低1回の壁登りまたは壁キックを必要とする。壁の上は幅260pxあり、着地してダッシュとスタミナを回復できる。途中で手を離しても下の連続床へ戻り、その場でやり直せる。区間内に踏み台の生物や回復アイテムは置かない。既存の任意ヒントも現在の配置に合わせ、新規ラベルは増やさない。

第6区間は外壁と中継3足場を取り除く。CP06を左へ60px広げ、入口の1280px/sのバネをx760へ置いて、旗と前区間からの着地位置を空ける。Springなしでは、相棒に乗ってから掴んで跳ぶ方法と保持ジャンプ・ダッシュを組み合わせても空中のクリスタルへ届かない。バネと最初の上ダッシュから、y-3650に並ぶDash CrystalとJump Crystalへ進む。両方をつなぐ経路のほか、手ぶらでも回復ダッシュだけ・靴だけの選択経路で到着できる。両クリスタルの使用を個別に必須とする履歴ロックは設けない。前区間から相棒を保持したまま運んでも通過できる。第6区間の出口は広いCP07の足場に置き換え、元の到着台は第12区間の頂上へ移した。CP07右の床は片面足場とし、従来のクリスタルへ飛び込む経路を塞がない。

## CP03の巻物ルート

バネ区間の後、CP03の左端に小さな巻物の印を置く。左へ近づくとカメラが横へ動き、空隙の向こうの幅260pxの足場と巻物を見せる。足場の端どうしは340px離れており、通常ジャンプだけでは渡れない。ジャンプの頂点近くで左へダッシュし、空中の巻物に触れて向こう側へ着地する。帰りもジャンプと右ダッシュで同じCP03へ戻る。着地でダッシュを回復でき、往復の間に回復アイテムは必要ない。

巻物の識別子は `tower / left_balcony_01`。接触すると追従し、安全な足場に0.2秒着地したら獲得を確定して保存する。確定前の落下やRでは元の位置へ戻り、確定後は落下・R・ステージ選択への帰還でも保存を保つ。追加2本を含む塔全体の配置総数は3個で、この1本だけ取得した場合は `1 / 3` を表示する。

寄り道の足場はCP03と同じ高さに置き、上へ登る足場・壁・クリスタルは増やさない。前半の6テーマとチェックポイントを保ち、巻物を取りに行かずに先へ進める。落下は従来のCP03から180px下の判定で戻し、新しい長距離の復帰は設けない。これは最初の横枝の追加であり、合意した本編9〜15分への増量全体は今後も続ける。

## 後半の応用と巻物ルート

第7区間は前区間から相棒を持って来られるため、入口を広い連続床にする。相棒を置いて壁へ歩き、600pxの壁を登る。上は幅260pxの休憩足場で、空中の緑のクリスタルと次の復帰足場を見ながら飛べる。前半から運んだ相棒を離れた場所から壁上へ投げ渡し、手ぶらで登って再取得する選択経路もある。再取得後に一度ジャンプして着地すると相棒を回復でき、回復クリスタルの代わりに使える。壁アクションはどちらでも必要とする。

第8区間は最初のバネで560px上の左の棚へ向かう。上昇を早い横ダッシュで止めず、頂点付近で左へ渡る。棚には幅440pxの余裕があり、次の小さなバネで400px上のCP09を目指せる。巻物の印からさらに左へ逸れ、小さなバネと斜めダッシュで空中の `tower / spring_turn_02` に触れ、幅260pxの別の棚へ着地する。帰りはジャンプと横ダッシュで元の棚へ戻る。分岐側に新しい復帰地点は置かず、CP08からのやり直しを保つ。

第9区間は安全な入口で相棒を保持し、靴の追加ジャンプと相棒の追加ジャンプを重ねて540px上の右の棚へ渡り、同じ高低差で左へ戻る。前区間から運んだ相棒もそのまま使える。440pxの高低差では相棒だけで靴を代用できるため、両方の空中資源をつなぐ高さにした。靴の区間では上方余白を260px、最後の最初の跳躍では160pxとして、次の棚やバネがポーズボタンに隠れないようにする。CP10の床は幅600pxあり、飛距離が少し短くても着地して旗へ歩ける。再開用の相棒は着地経路から離したx700に置き、運搬して来た相棒を持つプレイヤーの上昇を塞がない。第10区間は入口で相棒を保持し、対向する壁をキックで登る。短い壁では上ダッシュと同時に相棒を上へ投げ、手ぶらで壁を登って回収することで壁キックを省略できたため、壁を1200pxへ伸ばした。壁の上は幅360pxの休憩足場とし、相棒の追加ジャンプを回復してから440px上のCP11へ渡る。操作履歴による通行制限は加えていない。

第11区間は1650px/sのバネで浮いた丸い反射板の上へ回り込む。反射板は下から当たっても上昇を与えず、下降中に上面へ触れると1200px/sで跳ね返す。初めのバネから上面が見えるよう、カメラの上方余白を300pxにする。反射後だけ横風の領域へ入り、上ダッシュを合わせて左のCP12へ着地する。復帰足場を風の上へ置いて、立ち止まって次を観察できる。

CP12の左にも巻物の印を置く。空隙の向こうの棚へジャンプと斜めダッシュで渡り、`tower / wind_rest_03` を獲得して同じCP12へ戻る。両枝とも左右へ近づくとカメラが動き、巻物を取らずに主経路へ進める。第12区間は靴で右の棚へ渡り、棚のバネから左へ折り返す。緑のクリスタルでダッシュを回復して幅600pxの頂上へ着地し、到着台を押す。前区間から保持して来た相棒を、バネの頂点付近での追加ジャンプに使う選択経路も残す。バネと空中の追加資源を組み合わせる課題とし、両方の資源を使わせる履歴ロックは設けない。

今回の拡張は本編9〜15分という合意に向かう中間段階。操作を熟知した自動入力の所要時間と初見のプレイ時間を同一視せず、手動試遊での目標達成はまだ主張しない。

## 背景と地形

生活圏の惑星のふもとから、雲の上、星が見える上空へつながる。地表の街や山は序盤にだけ現れ、上昇すると下へ遠ざかる。雲と星には足場より遅い縦方向の視差を付け、空の色を高度に応じて滑らかに変える。

背景はプレイヤーを追うカメラの高さに合わせる。区間の境界では切り替えず、降下や落下からの復帰でも、その高さの景色へ戻る。地表の繰り返しや背景画像の縦引き伸ばしは行わない。足場・左右の壁は現行の生活圏の地形表現に揃え、見た目と当たり判定を一致させる。

背景の動作は `scripts/ascent_backdrop.gd`、地表と空の境目は `assets/environments/ascent.gdshader`、検証は `tests/ascent_backdrop_test.gd`。

## 復帰地点と落下

- 各区間の開始位置に幅240〜600pxの足場があり、端の小さな旗と中央の足跡で着地点を示す。未到達は中空の旗、現在の復帰地点は塗った旗と「↺」、到達済みは塗った旗と「✓」で区別し、番号を添える。旗と印に当たり判定はない。
- 上の区間の復帰足場に着地した時点で更新する。空中で通過するだけでは更新しない。
- 最高到達点から640px落ちるか、最新の復帰足場より180px下へ落ちると自動復帰する。
- R / Startも最新の復帰地点へ戻る。通常重力、速度0、ダッシュ・スタミナ回復、追加ジャンプなしで再開する。
- クリスタルを再出現させ、持てる生物を初期配置へ戻す。カメラも復帰地点へ戻る。
- 選択画面へ戻ると登塔中の復帰地点は破棄する。確定した巻物は保存する。

## 表示・操作

上部には塔の名前・区間番号・高度・ダッシュの使用可否・追加ジャンプ数・壁スタミナを表示する。ダッシュは使用可能なら「●」、使用済みなら「○」。復帰地点の番号を状態欄に重ねず、区間名と詳しい操作説明はヒント表示にまとめる。

Esc・Back／Selectまたは右上の「ポーズ [Esc]」で共通メニューを開く。背景・カメラ・物理・タイマーを含むゲーム全体を停止する。再開、ヒントの切り替え、最新の復帰地点からのやり直し、確認画面を経由するステージ選択への帰還を選べる。ヒントは初期非表示で、やり直しでも設定を保つ。詳しくは [ポーズメニュー](pause-menu.md) を参照。

頂上の到着台を押すとクリアを表示する。自動で画面遷移せず、メニューから戻れる。
