# ステージ2：星のぼりの塔

2026-10-31。参考図に沿って、旧34区間を主経路7室・寄り道3室の計10室へ作り直した。[合意した仕様](stage-2-redesign.md)、[Q1〜Q9の回答履歴](stage-2-redesign-decisions.md)を参照。

## コースと復帰

左下のふもとから出発し、バネと壁キック、トゲのある回廊、崩れる青い薄板をつないで、最上部のロケットを目指す。巻物は第2室と寄り道3室に各1本、計4本。巻物なしでも主経路を最後まで進める。

各部屋は1280×720以上とし、通常の倍率で部屋の端までキャラクターを追う。部屋の境界で切り替わり、前室と寄り道へ引き返せる。死亡・R・ポーズメニューのやり直しでは、現在の部屋へ最後に入った入口に戻る。再入室や再挑戦では板とクリスタルを復元する。

青い薄板は下から通れず、最初に上へ乗ってから0.5秒後に崩れる。離れてもカウントは続き、崩壊後2秒で復活する。プレイヤーと重なる間は復活を待つ。巻物は薄板では確定せず、崩れない安全な床へ0.2秒着地して確定する。

## 壁つかみジャンプ

壁をつかんでジャンプすると、重力に逆らう方向へ通常のジャンプ速度で跳ぶ。通常重力では真上、逆さでは下、左右の重力ではそれぞれ重力の反対方向になる。ジャンプを短く離すと高さも短くなる。上昇中はつかみ直しで勢いを打ち消さず、横方向は通常の空中操作で調整できる。

1回につき壁スタミナを0.5使う。つかみを離すか、壁から離れる方向を入れてジャンプすると、従来どおりスタミナを使わない壁キックになる。スタミナが尽きても壁キックは使える。ダッシュ、バネ、重力変更、気絶、やり直しで上ジャンプの状態を解除する。既存のジャンプ、壁キック、ダッシュ自体の速度は変更しない。

- `scripts/stage_2.gd`：部屋の移動と復帰、部屋の中に表示範囲を収めるカメラ、音楽、クリア演出。
- `scripts/tower_refill_crystal.gd`：既存のダッシュ回復動作を継承した、ステージ2用の緑の菱形。
- `scripts/crumbling_platform.gd`：従来どおり下から通れず、0.5秒で崩壊し、2秒で復活する。

- `tests/stage_2_test.gd`：全通り口の往復、入口復帰、部屋サイズとカメラ、トゲ・落下、板、巻物、静版、乗り込み。
