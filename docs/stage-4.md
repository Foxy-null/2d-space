# ステージ4：星渡りの回廊

全6面で、入口にいる緑の生物（Jump Creature）を持ったまま出口まで運ぶ。持っている間は壁登り・壁掴みができず、壁キックと生物の追加空中ジャンプを使って進む。追加ジャンプは足場への着地で回復する。既存のプレイヤーの性能は変更していない。

各面の幅は1280px。第2室は高さ1800pxで縦にカメラが追従し、ほか5室は1280×720の固定画面。出口の右端に生物を保持して着地すると次へ移動する。最終面は生物を保持して到着台を踏むとクリア。生物を置いたり投げたりして出口へ届けるだけでは通過できない。出口には枠に入った相棒の絵を置き、保持中は下の丸印がチェック印へ変わる。相棒の近くにいるときだけ掴むキーを表示する。常設の長い操作説明は省き、詳しいヒントはポーズメニューから開く。

| 面 | テーマ | 地形と攻略の違い |
| --- | --- | --- |
| 1 | 相棒と高い足場へ | 入口から420px上の幅450pxの片面足場へ、追加ジャンプとDashを組み合わせて上がる。着地して休み、先の低い足場へ下る |
| 2 | 壁キックの峡谷 | 相棒を保持し、1400pxの縦穴を左右の壁キックで上がる。幅240pxの足場で休み、後半の高低差を渡る |
| 3 | 低い天井の回廊 | 屋根の下にある低い足場を進む。追加ジャンプの早出しによる頭の衝突に注意 |
| 4 | 峠を越えて下る | 前半は高低差のある登り、後半は下りの着地位置を調整 |
| 5 | 離れ小島の大跳躍 | 相棒の追加ジャンプと上Dashで高い横風へ入り、630px先の幅230pxの島へ渡る。着地して休み、出口へ進む |
| 6 | 折り返しの頂 | 右へ上がり、左上の足場へ折り返してから右へ大きく渡る経路 |

天井には全幅1280pxにわたる赤いトゲを配置した。上端0〜32pxに危険を表示し、画面内で接触して復帰する。HUDは天井トゲを隠さない位置へ下げた。動くトゲの往復範囲は点線で表示する。接触判定は移動区間を調べ、ダッシュによるすり抜けも防ぐ。

動くトゲは合計22個（従来11個の2倍）。面1に2個、面2〜6に各4個を配置する。高い足場への踏み切り、峡谷後半、低い屋根の横移動、峠の下り、島への踏み切りと着地、折り返し後の渡りに関門を追加した。天井と第5室左端の固定トゲはこの個数に含めない。各トゲの移動範囲が実際の通過経路を横切ることもテストで確認する。

落下・トゲへの接触・R / Startで現在の入口へ戻り、生物・トゲ・能力を初期化する。部屋移動で復帰地点を更新する。進行はプレイ中のみ保持する。

Esc・Back／Selectまたは「ポーズ [Esc]」で共通メニューを開くと、背景を含むゲーム全体が停止する。操作ヒントは部屋ごとに異なり、切り替えてもポーズを維持する。チェックポイントからのやり直し後も表示設定を保つ。ステージ選択への帰還には確認画面を出し、Esc・Back／Selectでは確認からポーズ、ポーズからゲームへ戻る。詳しくは [ポーズメニュー](pause-menu.md) を参照。最終到着台の大型吹き出しは隠し、足場とトゲを見えるようにしている。

配置は `scripts/stage_4_room.gd`、進行は `scripts/stage_4.gd`、トゲの移動・天井判定は `scripts/spike_block.gd`。

## 確認

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script tests/stage_4_test.gd
```

成功時は `STAGE_4_TEST_OK`。全6面を生物の保持・実入力・壁登りなしで通過し、生物の追加ジャンプを各面で使用する。第1室は追加ジャンプとDashを組み合わせ、第2室は壁キックとDash、第5室も追加ジャンプと上Dash・高い横風を組み合わせ、第3・4・6室はDashなしで攻略する。全出口の手ぶら通過拒否、各面の天井への上向きダッシュによる接触復帰（左・中央・右）、移動トゲ、落下、再開、クリア、メニューを確認する。`-- --screenshots`で画面を保存、`-- --search`で入口の待ち時間を探索する。

`tests/corridor_companion_route_test.gd`は、第1室を異なる4つの開始時機で約5.38秒で通過し、追加ジャンプとDashを使うことを確認する。巡回トゲを停止し、相棒の追加ジャンプを利用できなくした216通りの踏み切り位置・Dash方向・時機・壁キックでも、高い足場と出口に届かないことを検証する。相棒の上からGrabと通常ジャンプを同時に入力する踏み台経路も、追加ジャンプなしでは届かない。追加ジャンプまでとDashまでの間隔を各16/20/24フレームに変えた9組み合わせは、上段へ到達できる。危険物による失敗と、足場の高さによる必須性を区別している。

画像は`docs/screenshots/celeste-corridor-room1-entry.png`と`celeste-corridor-room1-rest.png`。入口から上段と次の着地先が見え、第1室のHUDは入口足場より下に置き、巡回トゲと上段の相棒を隠さない。第3・4・6室では元の上側へ戻す。

第2室は入口床をy1700、最初の休憩台をy300へ置く。相棒を持つ間は壁登りができず、通常ジャンプ・相棒の追加ジャンプ・Dashだけでは1400pxの高さに届かない。相棒の背に乗り、Grabと通常ジャンプを同時に入力する方法や、上Dash中に相棒を投げてから手ぶらで登り直す方法も届かない。壁キックで上がった後は幅240pxの足場で静止して資源を回復できる。復帰地点は入口のまま、カメラは上昇と降下を追い、落下・トゲ・Rで相棒と資源も戻す。第2室のHUDは右下へ置き、左側の峡谷と後半の空中移動を隠さない。操作履歴によるロックや常設の説明は追加しない。

`tests/corridor_wall_route_test.gd`は982項目で、相棒を保持した実際の壁キックによる3つの開始時機、3秒の休憩、壁キックを使わないJump・相棒Jump・8方向Dashの288経路、相棒を踏み台にする24経路、上投げから手ぶらで登る6経路、巡回トゲへの接触、落下、Rを検証する。比較中の巡回トゲは停止し、高さによる必須性を分けて確認する。正常経路は15.85〜16.85秒、全6室の通過は`tests/stage_4_test.gd`の539項目で確認する。

第2室の画像：[入口](screenshots/corridor-wall/room2-entrance.png)、[峡谷を上がる途中](screenshots/corridor-wall/room2-climb.png)、[休憩台と次の着地先](screenshots/corridor-wall/room2-rest.png)。

第5室は、改修前には端まで歩いて通常Jumpを4回使うだけで、追加Jump・Dash・壁キックなしに次室へ通過できた。巡回トゲを有効にした実入口から死亡なしの3.57秒で再現し、入口で待った364フレームは攻略時間に含めない。

足場3枚をX=850〜1080px・上面Y=480pxの幅230pxの島1枚へ変え、入口の端X=220pxから630pxの隙間を作った。相棒の追加ジャンプと上Dashで、X=350〜650px・Y=100〜140pxの高い横風へ入る。追い風で島へ渡り、中央でDashと追加ジャンプを回復して出口へ進む。横風は既存のWindAreaを使い、加速2000・最大速度650とする。第5室のHUDは右下へ移し、風と踏み切りを隠さない。

独立レビューでは、実際に置いた相棒の背を離れてからコヨーテGrab＋通常Jumpを使い、追加Jumpなしで島から出口へ運べる経路を再現した。距離と高さだけで防ぐ案は、Grab可能な最後の遅い踏切と弱入力0.7の正規ルートの到達範囲が重なるため採用しなかった。追加Jumpなしでは届かない高い風を経由する配置にし、手ぶらで左壁を登る迂回は左端X=20〜52px・Y=100〜600pxの固定トゲで防ぐ。歯の根元を壁の右端に揃え、16pxの歯が壁に隠れず見えるようにした。4個の巡回を保ち、1個目だけ移動範囲をY=100〜610pxへ延ばし、位相を0.9に調整した。他の5室と共有Player・相棒・風の能力や運搬条件は変更せず、使用履歴のロックや常設説明も追加していない。

`tests/corridor_islands_route_test.gd`は2990項目で、通常横入力・0.85を各9組、0.7を8組（追加Jumpと上Dashの間隔を各16/20/24フレームから選ぶ）、巡回有効の11開始時機、島での3秒静止と再出発、R・落下・実巡回接触の復帰、次室のチェックポイントを確認する。巡回中は入口待機80〜110フレームを3フレーム刻みで変えてすべて4.22秒で通過した。入口の待機時間は攻略時間に含めない。

巡回を停止した比較では、実運搬で相棒の背上から跳ぶ63組、置き位置175/180pxからGrabが届く最後の歩数19/20フレームまで含めた実コヨーテ踏切234組、入口の通常/コヨーテJumpと8方向Dashの128組、Superdash3組（実発動2）、左壁へ接近する4組を調べる。432の有限入力例すべてで追加Jumpの使用・高い風への侵入・島への到達が0だった。支持接触・実Grab・通常Jumpが成立しない準備は負例に数えない。全6室の539項目では、4個の巡回の移動範囲が実経路を横切る検査を維持する。任意の入力列を網羅する証明ではなく、弱入力もソフトウェアによる入力強度の変更で、実機ゲームパッドは未検証。
