# ステージ4：星渡りの回廊

壁キックと動くトゲのタイミングを組み合わせる全6部屋。各部屋は1280×720でカメラを固定し、出口の右端まで進むと次の部屋へスライドする。

入口から左右の壁を交互に蹴って上がり、4本の縦壁を渡る。基本の移動性能は他ステージと共通。ダッシュは使用できるが、全室をダッシュなしで通過確認している。

| 部屋 | テーマ | 課題 |
| --- | --- | --- |
| 1 | 広い回廊 | 上下に動く2つのトゲ。中央に休憩足場 |
| 2 | 空中の関門 | 横移動・縦移動のトゲを避けて壁渡り |
| 3 | 相棒と越える | 緑の相棒を運び、追加ジャンプで高い壁へ |
| 4 | 横切る三連 | 横移動する3つのトゲを待って渡る |
| 5 | 上下の関門 | 上下に動く3つのトゲを避ける |
| 6 | 最後の三関門 | 相棒を運び、3つのトゲを越えて到着台へ |

Shift / ZL・ZRを押して相棒を保持する。部屋3は保持したまま出口へ進み、部屋6は保持したまま到着台を踏む。部屋移動で復帰地点を更新する。落下・トゲへの接触・R / Startで現在の入口へ戻り、相棒・トゲ・能力を初期化する。進行はプレイ中のみ保持する。

H / Y・△でお助けメニューを開くと移動とトゲが停止する。ヒントは操作説明で、経路線は表示しない。やり直してもヒント設定は維持する。Esc / Back・Selectはメニューを閉じ、メニュー外では選択画面へ戻る。

配置は `scripts/stage_4_room.gd`、進行は `scripts/stage_4.gd`。トゲの往復範囲を点線で表示し、接触判定はプレイヤーとトゲの移動区間も調べて高速移動中のすり抜けを防ぐ。部屋4・6の横移動範囲は240pxとし、最初の壁上で次の跳躍を待てる時間を確保する。

## 確認

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . --script tests/stage_4_test.gd
```

成功時は `STAGE_4_TEST_OK`。全6部屋を実入力で踏破し、ダッシュ未使用、相棒の追加ジャンプ、各トゲが実際の経路を横切ること、接触復帰、持ち運び条件、クリア、お助けメニューと再選択を検証する。`-- --search`を付けると入口での待ち時間を探索する。人による難易度の確認は今後の試遊で行う。
