# 回廊の運搬・投げ渡し・折り返し六室

[Issue #165](https://github.com/Foxy-null/2d-space/issues/165)。[探索設計の合意](celeste-exploration-design.md)を引き継ぐ初期仮説。旧30室の原点・地形・9IDと共有Player/物体/風の物理を保ち、第31〜36室と3巻物を追加する。旧第30室はCP31へ接続し、唯一のGoalを第36室へ移す。下表は着手前の仮説。確定した配置と実測結果は後段へ記録する。

| --- | --- | --- |

巻物は第31の壁上から左上、第33の反射後の棚から左上、第35の壁頂から上へ寄る3枝に置く。IDは `throw_left_10`・`rebound_upper_11`・`shaft_return_12`。控えめな既存巻物印、安全な確定棚、同じ主経路の棚へ戻る自然な帰路を備える。枝の棚を主課題への踏み台・回復の近道にしない。到着後も寄り道へ戻れることを確認する。

各室に異なる2〜3連携と実際に3秒静止できる観察場所を置く。静止待ちや平地往復を増量の根拠にしない。通常/実axis0.8の16/20/24fは離散比較として扱い、入力猶予の連続保証とはしない。成功時の再試行30秒以内、主経路では巻物未取得、実R/トゲ死後の再攻略、旧24の両運搬物から31への接続と全36室、旧9枝、新3枝の取消/確定/再訪/別process保存/選択12個と読み上げを検証する。

Hintの有無で主人公・実保持物のCollision全体、次の着地面、枝の巻物・印・帰路をnative PNGと実boundsで見る。初見/実機・本編9〜15分/巻物込み15〜24分は引き続き未達・未計測。後段には不合格を除いた最終結果と限界を記録する。

## 実装した配置

旧30室の原点と地形・物理を保ち、幅2240pxの第31・34室と幅2560pxの他4室を追加した。第32・35室は右入口から左へ進む。方向に合わせて入口・出口の片面床、端のトゲ、Spawn、到着枠、カメラ余白を反転する。旧第30室の出口からCP31へ移り、第36室だけが実Goalを持つ。

能力や物体の移動性能は変えず、履歴による解錠は追加していない。第31室の投げ渡しは実際の移動方法の一例であり、すべての投げ方を履歴で強制するものではない。第35室は相棒を持つと壁登りができない既存の制約を使う。

## 主経路の実入力

物理更新60Hz、固定描画60fps。`Input.action_press`の値1.0/0.8を直接使い、`Input.get_axis`で実値を確認する。Joypad deadzoneを通した値や実機での操作感とは区別する。相棒JumpやDashまでの間隔16/20/24fは離散的な6組であり、その間の全時機の連続保証ではない。

| 室 | 通常16/20/24fの秒数 | 実axis0.8の16/20/24fの秒数 |
| --- | --- | --- |
| 31 | 13.80 / 13.85 / 13.93 | 14.68 / 14.75 / 14.82 |
| 32 | 11.40 / 12.05 / 12.42 | 12.83 / 12.83 / 13.38 |
| 33 | 12.88 / 13.02 / 13.15 | 13.18 / 13.27 / 13.33 |
| 34 | 14.65 / 14.78 / 14.88 | 15.17 / 15.30 / 15.45 |
| 35 | 15.02 / 15.47 / 15.72 | 15.42 / 15.67 / 16.23 |
| 36 | 13.75 / 13.88 / 14.02 | 15.10 / 15.22 / 15.38 |

各値には安全を観測する3秒の静止と部屋移動を含む。静止は検査のためで、部屋の増量や操作所要時間には数えない。静止を除いた第32室の最短8.40秒など、10〜20秒という目安を下回る経路もある。異なる課題と30秒上限を確認した記録であり、待って所要時間を稼いではいない。実入力の36経路はすべて成功し、主経路では新旧巻物を取らない。主人公36×52pxと実保持物のCollision全体、Info・Pause・Hint・可視ClearCardを毎物理frameで検査し、画面外やHUD重なりがないこと、休憩から次の仕掛け・160px幅の着地面が見えることを確認する。

最終の通常3組は74222 / 75613 / 76577項目、弱3組は78617 / 79198 / 80612項目、計464839項目。合計31031frameを観測し、6ジョブすべて成功marker・終了0・警告なしだった。途中の通常16fでは終了時ObjectDB2個の警告が出ており、最終runに出なかったことを解消の証明とは扱わない。

## 有限の省略・代替比較

`corridor_sixth_required_test.gd`は実入口または実操作後の休憩を準備し、各室のSpring・靴・風・反射・回復・Up・壁キックを一つずつ無効にする。13条件×8方向Dash×12/20/28fの312経路を比較した。実保持・実Dashと必要な残りの仕掛けの接触を分けて確認する。

別に第34室でUpを使わず通常重力の帰路床へ入る24例、Upと回復を実接触してからDownなしで出る24例、第32・36室で本物の相棒の背からGrab/通常Jumpを同時入力して靴を省く各24例を試した。第35室の左右壁・通常/実背上・上投げ0/4/8fの12例は、実投げ速度・手ぶらの上登りを観測したうえで、壁キックなしで同じ相棒を頂へ回収できなかった。準備失敗や投げ拒否になった初期fixtureは負例へ数えず、実支持を再確認して修正した。

任意棚が本編の課題を省く足場にならない比較は、3枝の確定床から残りのSpring/回復/風を一つ無効にし、8方向Dashの計24例。これらも目的床や次室へ届かなかった。代表入力の有限比較であり、任意の入力列や投げた物体を追うすべての戦略についての不可能証明ではない。

## 再現コマンド

共有環境では`/tmp/celeste-godot-slot.py`経由で1本ずつ起動し、終了後2秒空ける。Godotの`--path`はこの作業コピーを指定する。以下はGodot以降の主な引数。

```sh
--headless --fixed-fps 60 --script res://tests/corridor_sixth_route_test.gd -- --profile=5 --hints
--headless --fixed-fps 60 --script res://tests/corridor_sixth_required_test.gd -- --section=36 --delay=20
--headless --fixed-fps 60 --script res://tests/corridor_sixth_alternative_test.gd -- --throws-only
--headless --fixed-fps 60 --script res://tests/corridor_sixth_scroll_test.gd -- --weak --keep-fixture
--headless --fixed-fps 60 --script res://tests/corridor_sixth_reload_test.gd -- --fixture=user://出力されたPID付きファイル.cfg
```

`--profile=0..5`、`--section=31..36`で有限の単位に分けられる。省略試験は`--delay=12/20/28`、`--up-return`、`--down-only`、背上比較は`--section=32/36`、枝棚からの比較は`corridor_sixth_branch_required_test.gd --section=31/33/35`。成功markerと終了0の両方を確認する。

## 復帰・旧ルートと共通フロー

新6室の実R、実移動からのトゲ接触、左向き2室の両端境界、相棒・能力の復元と再攻略、旧第30室からCP31へ実際に運んだ個体の初期化を68192項目で確認した。さらに`corridor_sixth_resource_retry_test.gd`の48項目では、新第32・36室の靴と第33・34室のDash回復をそれぞれ実接触した物理frameで止め、直後の1frameでRを押す。同じノードの可用性・接触判定・タイマー初期化、遅延再消失がないこと、実再取得まで各2回を確認し、ステージ側の追加修正は不要だった。

全36室の1257項目と、旧9枝を含むexpansion422 / more257 / wide8173 / fourth31610 / fifth42080、旧第24室の緑・赤からCP25への54707項目を再実行した。共通clear71 / arrival388 / hint occlusion57 / scroll room transfer48 / selection144もすべて成功marker・終了0。共通のユーザー設定を書き換える検査はXDG_DATA_HOMEを一時ディレクトリへ隔離し、他の保存検査はPID付き専用ファイルを使う。

実相棒支持の第36室でも終了時ObjectDB2個の警告が出た。通常16fの警告と合わせて未解消として残し、ゲーム内の成功判定・操作の成立・終了0と区別する。初見の人による所要時間・実機ゲームパッド・本編9〜15分/巻物込み15〜24分は未検証であり、この拡張で達成したとは扱わない。

第36室のHintON nativeでは、クリア直後だけHintが上端へ移り、天井の歯と文字が重なる実画像を検出した。攻略中と同じ下側位置を保つよう完了時の例外だけを除き、実CeilingSpikesの危険範囲とHint実rectが重ならない正例検査を加えた。地形と物理は変えていない。

第33・35室の巻物入口の小さな印は、nativeの静止位置で実相棒の顔へ重なる例があったため、印だけ70px上げた。巻物・確定棚と主経路物理は保つ。第35室の巻物棚と高い風の弧でも天井の歯と上Hintが重なった。Y110案は弱入力の帰還後ジャンプで実相棒と約2.3px重なり不合格。worldY520より上では画面Y560、他は従来Y12とし、通常/弱の枝往復34723項目と弱16/20/24fの主経路、nativeで実body/held/Hint/天井の非交差を全frame確認した。

全frameの天井/Hint検査を追加すると、第31室のSpring後の高い弧でも重なりが検出された。第31・35室はworldY520より上で画面Y560へHintを寄せ、その他では従来位置を保つ共通の1条件とした。第36室は上層と完了後も同じ下側位置を維持する。実際に重なった移動を含めた最終36経路で再確認している。
