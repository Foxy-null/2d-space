# 音源

BGM・ジャンプ・ダッシュ・クリアSEには、提供された「ぶっとび宇宙.zip」の音源を使用しています。

C系統（ステージ1・4）の通常版・静版は、提供された改訂版「ステージ系統 C_通常_改.mp3」「ステージ系統 C_静_改.mp3」に差し替えています。

| 画面・ステージ | BGM |
| --- | --- |
| タイトル・ステージ選択 | タイトル |
| 1・4 | C系統 |
| 2・5 | A系統 |
| 3・6 | B系統 |

MP3のBGMは再エンコードせずに取り込み、Godotのインポート設定で通常版・静版ともに全曲ループを有効にしています。クリア画面を表示すると通常版を停止し、クリアSEを一度再生してから、そのステージの静版へ切り替えます。画面を離れた場合は切り替えを取り消します。

ジャンプ・ダッシュ・クリアSEは44.1 kHz・ステレオ・16 bit PCMのWAVに変換しました。前後の無音を−60 dBのしきい値でカットし、末尾の2 msだけフェードアウトして切断音を防いでいます。音の途中の間は残しています。

| 元ファイル | 取り込み先 | カット後の長さ |
| --- | --- | --- |
| ジャンプSE.mp3 | jump.wav | 約0.24秒 |
| ダッシュSE.mp3 | dash.wav | 約0.11秒 |
| ステージクリア.mp3 | clear.wav | 約5.29秒 |

ジャンプSEは通常ジャンプ、壁キック、追加ジャンプ、相棒の追加ジャンプ、Superdashに使用し、ダッシュSEはダッシュ開始時に使用します。到着台などの既存の効果音はそのまま使用します。

音声テストは `tests/game_audio_test.gd` です。Godot 4.7.2では、音源を再生したまま終了すると、AudioStreamMP3とAudioStreamPlaybackMP3の解放警告が出る場合があります。[Godot側の既知問題](https://github.com/godotengine/godot/issues/76745)と同じ終了時の症状で、再生・ループ・画面移動時の停止はテストで確認しています。

## ボタン・メニュー・巻物の効果音

[効果音ラボ](https://soundeffect-lab.info/)のフリー素材を使用しています。2026年10月31日に[利用規約](https://soundeffect-lab.info/agreement/)を確認しました。商用利用・加工は無料、クレジット表記は任意です。音源の著作権は提供元にあり、素材単体の再配布は禁止されています。本ゲームの操作音・演出音として組み込んでいます。

| 操作 | 素材名 | 掲載ページ | 取り込み先 | 長さ |
| --- | --- | --- | --- | --- |
| ボタンのフォーカス移動・マウスホバー | カーソル移動1 | [ボタン・システム音](https://soundeffect-lab.info/sound/button/) | ui-move.wav | 約0.14秒 |
| ボタン決定 | 決定ボタンを押す22 | 同上 | ui-select.wav | 約0.47秒 |
| Esc・ポーズボタンでメニューを開く | キャンセル9（ザッ） | 同上 | menu-open.wav | 約0.25秒 |
| 未獲得の巻物に触れて追従が始まる | ちょこっと触る | [演出・アニメ](https://soundeffect-lab.info/sound/anime/) | scroll-touch.wav | 約0.46秒 |
| 安全な着地後、巻物の保存に成功する | パッ | 同上 | scroll-collect.wav | 約0.17秒 |

44.1 kHz・ステレオ・16 bit PCMのWAVに変換し、前後の無音を−60 dBでカット、末尾2 msをフェードアウトしています。移動・メニュー・接触音は再生時に4 dB下げています。すべて1回再生です。

ボタン音はタイトル・ステージ選択・ポーズ・操作設定・確認ダイアログの共通処理で鳴ります。マウスとフォーカスが同じフレームに変わっても移動音は重複させず、決定音は画面移動後も最後まで再生します。巻物の獲得音は保存に失敗した場合や獲得済みの場合には鳴りません。

## アイリスと死亡の効果音

| 用途 | 素材名・出典 | 取り込み先 | 再生時間・音量 |
| --- | --- | --- | --- |
| 死亡時に円を閉じる | 効果音ラボ「縮む」・[演出・アニメ](https://soundeffect-lab.info/sound/anime/) | iris-close.wav | 0.30秒・−8 dB |
| 入場・復帰時に円を開く | 効果音ラボ「伸びる」・同上 | iris-open.wav | 0.50秒・−8 dB |
| 死亡確定時の短い衝撃 | OtoLogic「SNES RPG05-10（ダメージ）」・[RPG用セット](https://otologic.jp/free/se/game-rpg01.html) | death.wav | 約0.21秒・−4 dB |

2026年10月31日に取得しました。効果音ラボの利用条件は上記と同じです。死亡音の作者は[OtoLogic](https://otologic.jp/)、ライセンスは[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)です。[提供元の利用規約](https://otologic.jp/free/license.html)に従い、タイトル画面にも作者・ライセンス・編集済みの表記を置いています。

全3音を44.1 kHz・ステレオ・16 bit PCMのWAVへ変換し、前後の無音を−60 dBで除去、末尾2 msをフェードアウトしています。円の2音は音程を保ったまま0.30秒・0.50秒へ時間圧縮しました。声素材は使用していません。BGMは死亡中も通常速度で継続し、ポーズ・操作設定・体験モードの警告中は円の音と死亡音を映像と一緒に止めます。手動リトライや部屋移動では死亡音を鳴らしません。

ステージ2の寄り道3室では攻略中もA静版を使い、主経路へ戻るとA通常版へ切り替えます。同じ版の更新で曲を再開せず、クリアSEの再生を部屋の切り替えで中断しません。
