# 音源

提供された「ぶっとび宇宙.zip」の音源を使用しています。

| 画面・ステージ | BGM |
| --- | --- |
| タイトル・ステージ選択 | タイトル |
| 1・4 | C系統 |
| 2・5 | A系統 |
| 3・6 | B系統 |

MP3のBGMは再エンコードせずに取り込み、Godotのインポート設定で通常版・静版ともに全曲ループを有効にしています。クリア画面を表示すると通常版を停止し、クリアSEを一度再生してから、そのステージの静版へ切り替えます。画面を離れた場合は切り替えを取り消します。

ジャンプ・ダッシュ・クリアSEは44.1 kHz・ステレオ・16 bit PCMのWAVに変換しました。前後の無音を−60 dBのしきい値でカットし、末尾の2 msだけフェードアウトして切断音を防いでいます。音の途中の間は残しています。

| 元ファイル | 取り込み先 | カット後の長さ |
| --- | --- | --- |
| ジャンプSE.mp3 | jump.wav | 約0.24秒 |
| ダッシュSE.mp3 | dash.wav | 約0.11秒 |
| ステージクリア.mp3 | clear.wav | 約5.29秒 |

ジャンプSEは通常ジャンプ、壁キック、追加ジャンプ、相棒の追加ジャンプ、Superdashに使用し、ダッシュSEはダッシュ開始時に使用します。到着台などの既存の効果音はそのまま使用します。

音声テストは `tests/game_audio_test.gd` です。Godot 4.7.2では、音源を再生したまま終了すると、AudioStreamMP3とAudioStreamPlaybackMP3の解放警告が出る場合があります。[Godot側の既知問題](https://github.com/godotengine/godot/issues/76745)と同じ終了時の症状で、再生・ループ・画面移動時の停止はテストで確認しています。
